# MyHealth v1.3 Release Notes / 变更日志

**Date:** 2026-06-14

---

## 自 v1.2 以来的变更

### 新增功能

| 功能 | 说明 |
|------|------|
| 🎯 关卡预览 | 点击关卡卡片弹出预览：敌人属性、Boss词缀说明、胜率估算，确认后再挑战 |
| 📜 属性变更日志增强 | 日志 reason 从"周奖励+N"扩展为"容量3200kg·有效有氧90min·周奖励+20·惩罚攻-4防-2"完整信息 |
| 🌡️ 有氧强度系统 | 低/中/高三级强度倍率（×1/×2/×3），影响防御属性计算 |
| ➕ 自定义运动类型 | Cardio Tab 支持自定义运动名称、图标、默认强度 |
| 📋 有氧训练计划 | 创建/编辑/删除/执行有氧计划，含分段时长和休息倒计时 |
| 🏆 关卡与属性记录 | 历史最高关卡/攻击/防御/生命 + 按月可查本月最佳 |
| 🔄 月导航 | 挑战记录支持 ◀▶ 按月浏览 |

### UI 优化

| 改进 | 说明 |
|------|------|
| 🎨 全局 CSS 重构 | 卡片阴影、hover 动效、深色主题加深、按钮辉光、模态模糊背景 |
| 📊 折线图升级 | 平滑贝塞尔曲线替代直线，白底填充数据点，步进式 X 轴标签 |
| 📅 热力图 | 圆角单元格、hover 放大、橙色双圈 today 标识、柔化颜色阶梯 |
| 🔀 Profile 子 Tab | 拆分为"个人数据"和"训练数据"两个子页面 |
| 📈 训练统计面板 | 月度容量趋势图、累计天数、最爱动作 TOP5 |
| 🏷️ 本周统计增强 | 添加单位标识（次/kg）、显示真实最爱动作 + 训练天数 |

### Bug 修复

| 修复 | 说明 |
|------|------|
| 🩹 有氧计划按钮不显示 | 空计划时也渲染"+ 新建有氧计划"按钮 |
| 🩹 热力图仅记录力量 | 现同时统计力量次数 + 有氧分钟数作为活动分 |
| 🩹 热力图双标题 | 去除 HTML 中静态标题，仅保留 JS 动态生成 |
| 🩹 防御公式 | `10+⌊时长/6⌋` → `10+⌊有效时长/15⌋`（有效时长=时长×强度） |
| 🩹 战斗 HP 条 | 分母修复为 player.maxHP |
| 🩹 NaN 体重 | 提交前验证 isNaN/w≤0/w>500 |
| 🩹 图表除零 | `range = Math.max(1, max-min)` |
| 🩹 setTheme 空值 | 添加 null guard |
| 🩹 训练定时器泄漏 | 关闭遮罩时清除 setInterval |
| 🩹 热力图年份越界 | 限制 2020 ~ 明年 |
| 🩹 图表文字描边 | 去除最新值标注的 strokeText |
