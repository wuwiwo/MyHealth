## 0. 一句话结论

**含技能口径下，稳过带下沿未变（仍稳过到 `g16` = 100%），但边界带被「拆成两半」：`g17` 由 v2.2.19 的 63% 掉到 **35%**（跌破半开，成为**可过档里最难的一关**），`g18` 由 93% 掉到 **83%**（仍在边界带上沿）；`g19` 依然是墙（恒 0%），`g20` 未变（0%）；`g21~g24` 恒 0%。**

**位移经同机同脚本逐版 bisect 一次性定位到唯一一层 `v2.2.20`**（敌群天赋「接成长」）：
`g17` 63→35、`g18` 93→83、无技能 `g15` 65→35 **全部发生在该版**；`v2.2.22`（威吓幅度区间化 + 槽位立即开放 3 + 掉落倍率）与 `v2.2.23`（等级系统）**逐格零变化**。

**因此本轮任务的四个预期里，一个落空、三个被确认**：
- ❌ 「`v2.2.22` 威吓区间化会动 `g16/g22/g24`」→ **实测零变化**（原因见 §3.3：本阶梯的 `intimidate` 携带者全部落在 100% 或 0% 的饱和档，**结构上不可观测**）。
- ✅ 「`v2.2.20` 接成长 → g10+ 吃区间上端 → 偏难」→ **确认，且就是本批唯一动过档位的一版**。
- ✅ 「`v2.2.23` 对现网零影响」→ **确认（逐格一致 + 结构性为零，见 §2.5）**。
- ✅ 「`g19` 仍是墙」→ **确认（40/40 全败）**。

**本轮最重要的新发现是：`g17` 反超成为全阶梯唯一的「半开」瓶颈（35%），比 `g18`（83%）整整低 48pp** —— 而 v2.2.15 时 `g17`(95%) 还**高于** `g18`(90%)。这个倒挂在 v2.2.16 出现、在 v2.2.20 被放大成 48pp。

不含技能时整条阶梯同样左移：`g15` 由 v2.2.19 的 **65%** 掉到 **35%**（40t），`g16` 100%，`g17` 起全为 0%。

  后者（v2.2.21 挑战路径 + v2.2.22 敌群补线）是**纯经济**，不改战斗数值、不改随机流。→ 对通过率零影响。

### 2.4 固定种子（可复现的关键）

- 沙箱随机种子：`20260929 + i * 7919`（`i` = 第 i 次 trial）
- 战斗种子：`1000 + i`

- 上限 600 步（超时判负）

### 2.5 `v2.2.23` 等级系统为什么必然「零影响」（双重保证）

1. **真实游戏侧**：`LEVEL_TIERS` 从 lv10 起才有效果，新档与迁移档都是 **lv1** → 玩家等级加成 = 0；宠物同理。
2. **本测量侧（更强）**：`level-system.js` **根本不在脚本的 `FILES` 里**，且两处消费点都有守卫
   （`battle-group.js:436` / `battle-group.js:620`：`if (typeof levelDamageAdjust === 'function') dmg = levelDamageAdjust(actor, target, dmg);`）
   → 沙箱内该函数不存在，**连函数调用都不会发生**。

→ 因此 §3.2 bisect 表里 `v2.2.22` 与 `v2.2.23` **逐格完全一致是预期结果，不是「测不出来」**。

### 3.1 结论（逐条回答任务四问）

## 4. 异常 / 存疑点

1. **`g17` 反超成为全阶梯唯一「半开」瓶颈（35%），且比 `g18`（83%）低 48pp —— 本轮最重要的发现，也是本轮唯一的显著恶化。**
   位移单层可定位到 `v2.2.20`（见 §3.2）。**如实记录，不粉饰。**
2. **档位倒挂（`g17` < `g18`）不是本轮新出现的，但被本轮放大到最大**：
   | 版本 | g17（含技能 40t） | g18 | 倒挂幅度 |
   |---|---|---|---|
   | v2.2.15 | 95% | 90% | 无倒挂（g17 更高） |
   | v2.2.16 | 40% | 70% | 30pp（**倒挂在此出现**） |
   | v2.2.17 / v2.2.18 | 57% | 70% | 13pp |
   | v2.2.19 | 63% | 93% | 30pp |
   | **v2.2.23** | **35%** | **83%** | **48pp（历史最大）** |
   → **`g17` 的难度曲线与 `g18` 已经彻底脱钩**，阶梯在 `g17` 处出现一个**尖锐低谷**。
3. **`g19` 是局部低谷的「倒挂」现象在通过率指标上仍不可观察**：`g19` 与 `g20` **均为 0/40**，两者无差别。
   ⚠️ 这**不代表**倒挂被修好（HANDOFF §10 的「g19 需 6.5× / g20 需 4.3×」问题依然存在），只是**通过率把它盖住了**。
4. **12 trials 再次出错，且本轮是「双向」**：含技能 `g17` 12t=**42%** vs 40t=**35%**（**高估 7pp**）；
   无技能 `g15` 12t=**25%** vs 40t=**35%**（**低估 10pp**）。
   → 与 v2.2.15 / v2.2.18 的结论完全一致：**12 trials 只适合分辨「0 / 中间 / 100」三档，凡落在 0~100% 之间的点必须 40t 复核。**
   （本轮 `g18` 12t=83% 与 40t 恰好相等，属**运气**，不能当成「12t 也够用」的证据。）
5. **无技能口径的 `g15` 从 65% 继续掉到 35%**：该列不含玩家技能，故只受「敌方天赋 + 宠物规则」影响

   量级 = 40t 抽样噪声（p≈0.4 时 SE ≈ 7.7pp）的约 1.6 倍，**方向可疑但不足以断言**；
   机制上可解释（4 宠把队伍血量拉高 → 战斗回合数变多 → 多吃 `roughskin` 反伤与 `lazy` 减伤），
