## 5. 技能区间接进非攻击通道

### 背景

`page/skill.js`：
- `skillRangeT(unit)` —— 炼化等级 ÷ 稀有度炼化上限 → t ∈ [0,1]（v2.1.23 已定为驱动源）
- `skillValue(skill, key, t)` —— 在 `skill.range[key] = [低,高]` 里线性插值
- `castSkill()` 注入 `ctx.sv`（v2.1.23 已做），让 `effects` 里也能拿到 `sv`

**现状**：`sv` 目前只在「攻击威力」被消费。以下仍是固定值：

| 通道 | 涉及技能 | 固定值位置 |
|---|---|---|
| 治疗量（heals） | 圣光治愈、睡觉 | `skill.js` SKILLS 定义里的 `heals[].amount` |
| 状态幅度（statusApps） | 打湿（魂防 / 命中）、闪耀（降命） | `statusApps[].modsPct` 等 |
| 增益幅度（buffs） | 战意灌注 | `buffs[].value` |
| 睡眠时长 | 睡觉 | `statusApps[].duration` |

### 做法

1. 在 `SKILLS` 里给上述键补 `range`（低→高），与攻击威力同一套写法
2. `applySkillEffects` 消费 `ctx.sv`：heals / statusApps / buffs 三类通道全部走 `skillValue()`
3. **数值不改动意图**：低值 = 现在的固定值，高值 = 设计文档给的上限；没有设计上限的，低值保持不变、高值暂定低值 ×1.5 并标 [PLACEHOLDER]

### 风险

- 睡觉时长有「同回合末 ageStatuses 先扣 1」的坑（v2.1.24 记录过），改 duration 时 must +1
- 治疗/增益变大可能让平衡变易，做完要跑 `balance-sim.js` 复核 g1~g13 仍 100%

## 6. 动作百科媒体 —— ✅ 已完成（实测可访问，无需改码）

**结论：媒体正常，Vercel 上可访问。**

实测（curl 走代理 `127.0.0.1:7897`）：

| URL | 结果 |
|---|---|
| `https://my-health-six.vercel.app/` | 200 |
| `/config.js` | 200 ← **说明 Vercel 部署根目录 = `page/`** |
| `/page/config.js` | 404 |
| `/media/images/0109-dZl9Q27.jpg` | **200 ✅** |
| `/page/media/images/0109-dZl9Q27.jpg` | 404 |

- `page/media/` 共 **38 个文件已入库**（`images/` + `videos/`），不是只存在于本地
- `MEDIA_BASE = ''`（`page/config.js:4`），走本地 `media/<rel>` 相对路径
- 相对路径的解析基准是 **HTML 文件本身**，所以两种环境都对：
  - 线上文档 `/index.html` → `media/...` → `/media/...` ✅
  - 本地文档 `/page/index.html` → `media/...` → `/page/media/...` ✅

→ **无需改代码**。待办可勾选，注明「已实测 200」。

⚠️ 注意一个易错点：Vercel 部署根目录是 `page/`，所以**线上 URL 不带 `page/` 前缀**。
之前用 `/page/media/...` 去测会得到 404，那是路径写错，不是资源缺失。
