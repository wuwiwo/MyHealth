## 0. 一句话结论

**含技能口径下，档位相对 v2.2.15 基线「向下迁移」：稳过带下沿未变（仍稳过到 `g16`，100%），但边界带整体下沉 —— `g17` 由 95% → **57%**、`g18` 由 90% → **70%**；`g19` 仍是墙（恒 0%）、且 `g20` 由「近墙 8%」**并入墙（0%）**；`g21~g24` 仍恒 0%。**

**本轮的决定性发现是：这整段下移经「同机同脚本逐版 bisect」定位到**唯一一层 `v2.2.16`**（敌群天赋固化 + WP-C 前半）——`g17` 95→40、`g18` 90→70、`g20` 8→0、无技能 `g15` 88→70 全部发生在该版；`v2.2.17` 只把 `g17` 拉回 40→57，`v2.2.18`（雷霆冲撞反冲）未再改变任何档位。**

**因此本轮任务的四个预期里有两个与实测相反：`g17`/`g18` 不是「更稳」而是「更难」；`g20` 不是「脱离近墙」而是「并入墙」。`g19` 仍是墙则被再次确认（40/40 全败）。**

不含技能时整条阶梯同样左移：`g15` 掉到 **65%**（40t，v2.2.15 为 88%），`g16` 100%，`g17` 起全为 0%。

### 2.3 未含（本次测量的已知空白）

- **宝珠**：`seedStore` 写 `orbs: []` → 宠物宝珠 0 颗。
- **宠物养成/精炼**：4 只均为 `refineLevel 0` / `refineStats {}` / `skillLevels {}` / `stage: mature` = **裸图鉴下限**；
  参战宠固定为 `sparkle(R) / chirpbird(SR) / icecrystal(SSR) / dream(UR)`（脚本内 `PETS` 常量，非玩家实际编队）。
  ⚠️ 这也意味着 **v2.2.16/17 落地的宠物技能（§2.1~§2.14）在本档走的是 `skillLevels {}` = Lv0 的基础值**，其「升级后更强」的一面**不在测量面内**。
- **宠物天赋/词条**：未挂任何 `petOnly` 天赋。
- **玩家侧**：无炼魂、无装备、无词条（只走 `inheritGroupStats` 的 50% 继承 + 技能）。
- **敌群天赋「接成长」（WP-F，至今未做）**：`talent.js` 那批固定值仍**不随大关成长**。
  ⚠️ **注意区分**：v2.2.16 做的是「**天赋固化**」（同关每次天赋相同、可复现），**不等于**「天赋接成长」；本轮 `g19~g24` 的高墙角仍可能部分源于后者。
- **装备槽位纪律被绕过**：游戏内为「3 槽、同类型限 1」；而 `attachPlayerSkills` **不做任何槽位/类型校验**，
  脚本直接把 5 个技能（含 2 个 support：`vitality` + `spotlight`）塞进 `loadout`。
  → **本档是「技能上满」的理论配装上界，超出游戏内 3 槽上限，不是当前 UI 能实现的实际配装。**
- **幸运口袋不在测量面内**：它是**战斗胜利结算的掉落**天赋，且脚本的 4 只参战宠**不含**携带者小负鼠（`possum`），
  胜负循环也在 `gb.done` 即停、不进入 `groupVictoryReward()`。→ 对通过率零影响（只影响掉落层）。

### 2.4 固定种子（可复现的关键）

## 3. 与 v2.2.15 的定性对比（**只做定性判断，不做减法**）

> 对比对象：v2.2.15 冻结快照基线（commit `03d1e8f`，含技能 40 trials：`g15 100% / g16 100% / g17 95% / g18 90% / g19 0%（墙） / g20 8%`）。
> ✅ **本轮为了归因，额外在**同机、同一份脚本**下把 `03d1e8f` 重跑了一遍 40t，**逐格复现了公布值**（`g17 95% / g18 90% / g19 0% / g20 8%`，无技能 `g15 88%`）——故下表用「同机重跑值」，排除了机器/脚本差异。
> ⚠️ 仍**不允许把两次数字相减当唯一结论**（中间叠了 v2.2.16/17/18 三层会改变随机流的改动，见 §6）；但**量级远超抽样噪声**，方向可信。

| 大关 | v2.2.15 基线（含技能 40t） | v2.2.18（含技能 40t） | 定性判定 |
|---|---|---|---|
| g15 | 100% | 100% | **稳过带未变** |
| g16 | 100% | 100% | **稳过带未变（稳过带下沿）** |
| **g17** | 95% | **57%** | ⚠️ **显著下移（−38pp），脱离 80~95% 边界带上沿** |
| **g18** | **90%** | **70%** | ⚠️ **下移（−20pp），仍在边界带但更靠下** |
| **g19** | 0% | 0% | **仍为墙，结论未翻转 ✓** |
| **g20** | 8% | **0%** | ⚠️ **由「近墙（偶可过）」并入墙（不再偶可过）** |
| g21~g24 | 0% | 0% | **未变** |

无技能口径（40t）：`g15` **88% → 65%（−23pp）**、`g16` 100% → 100%、`g17` 起两版均恒 0%。

### 3.1 结论（逐条回答任务四问）

- **档位有没有迁移？** → **有，且是**向下**迁移。稳过带**下沿不变**（仍稳过到 `g16` = 100%），但**边界带（`g17`/`g18`）整体下沉**（95→57、90→70），无技能口径的 `g15` 也从 88% 掉到 65%。
- **`g19` 还是不是墙？** → **是。** 40 trials 下 **0/40**，恒 0%，未翻转。
- **`g17`/`g18` 还在不在边界带？** → **在，但不是「更稳」而是「更难」。** `g17` 从「近满的边界（95%）」掉到 **57%**（已接近半开）；`g18` 70%。两者都**仍靠技能续命**（无技能口径下两版都是 0%）。
- **`g20` 有没有脱离近墙？** → **脱离了，但方向相反**：8% → **0%**，已与 `g19` 无差别。

### 3.2 机制归因：**同机同脚本逐版 bisect**（本轮决定性证据）

在同一台机器上用**完全相同**的 `balance-pets-ab.js` 对四个冻结快照各跑一遍 40t（含技能），只换快照：

| 快照 (commit) | 含技能 g17 | 含技能 g18 | 含技能 g19 | 含技能 g20 | 无技能 g15 |
|---|---|---|---|---|---|
| v2.2.15 (`03d1e8f`) | 95% | 90% | 0% | 8% | 88% |
| **v2.2.16 (`4f3fcfe`)** | **40%** | **70%** | 0% | **0%** | **70%** |
| v2.2.17 (`f4111c6`) | 57% | 70% | 0% | 0% | 65% |
| v2.2.18 (`7f1cf01`) | 57% | 70% | 0% | 0% | 65% |

**脚本同一性已证**：`git diff 03d1e8f 7f1cf01 -- scripts/balance-pets-ab.js` **为空**（脚本在四版之间未改）。

**归因结论**：
1. **整段下移全部发生在 `v2.2.16` 这一层**：`g17` 95→40、`g18` 90→70、`g20` 8→0、无技能 `g15` 88→70。
   v2.2.16 的提交内容正是「**WP-C 前半（宠物技能 §2.1~§2.7）+ WP-F 第一批（死配置单源化 + **敌群天赋固化**）**」。
2. **`v2.2.17` 只把 `g17` 拉回 40→57**（16/40 → 23/40，+17pp），其余档位未动。
3. **`v2.2.18`（雷霆冲撞自身 35% 反冲）未再改变任何档位**——与 `v2.2.17` **逐格一致**（g15/g16/g17/g18/g19/g20 全同）。
→ 因此「档位迁移」是**单层、可定位**的，不是三层叠加的模糊结果。

⚠️ **残留不确定性**：`v2.2.16` 内部仍是两个子改动**同版落地**（敌群天赋固化 + 宠物技能 §2.1~§2.7），
本报告**无法把两者彻底分离**。下方的编成证据把天平指向「天赋固化」，但**未证伪**宠物技能侧的贡献。

用一次性只读探针（写在 scratchpad，不入库）枚举各 Boss 关的敌方编成：

| Boss 关 | Boss | Boss 技能 | **Boss 天赋（固化后）** | 该关精英天赋 |
|---|---|---|---|---|

| **g18-10** | Boss·战争领主 | `[cleanse, bulwark]` | `magicmirror / vigor / bloodthirst`（3 个） | `[bloodthirst,blade]` + `[magicshield,blade]` |
| **g19-10** | Boss·暗龙 | `[lastword, doom]` | `vigor / regen / vengeance`（3 个） | `[bloodthirst,flutter]` + `[blade,magicshield]` |
| **g20-10** | Boss·深渊之主 | `[blizzard, heal]` | **`plain / magicshield / regen / roughskin`（4 个）** | `[blade,vengeance]` + `[blade,intimidate]` |

天赋效果速查（`page/talent.js` 实测取值）：`blade` 利刃 = 普攻伤害 +10%+level×0.5%（本档 lv10 → **+15%**）；
`vigor` 强健 = 自身攻/防/魂攻/魂防 **+15%**；`vengeance` 复仇 = 每损失 20% 生命、攻与魂攻 **+10%**；
`roughskin` 粗糙皮肤 = 受普攻时**反伤攻击者 15%**（无视防御）；`magicshield` 魔法盾 = 受魂攻伤害降低；
`bloodthirst` 嗜血 = 造成伤害回 20% 血；`regen` 再生 = 每 2~3 回合回血；`plain` 朴实 = 免疫一切改属性的增益/减益；
`magicmirror` 魔法镜 = 受指向性辅助 30% 免疫并反弹负面；`intimidate` 威吓 = 开场降 1 名敌方攻击。

**观察**：
1. **固化确实按大关分配了不同天赋数**：`g20-10` Boss 拿 **4 个**、`g21/g23/g24` Boss 各只剩 **1 个**——与 `doc/HANDOFF.md` v2.2.16 记录「g8/g21/g23/g24 的 Boss 只剩 1 个天赋、g20-10 拿 4 个」**逐条吻合**。
2. **`g17-10` Boss 的 4 个天赋是纯进攻/反伤套装**（`blade` 增伤 + `vengeance` 残血增攻 + `roughskin` 反伤 + `vigor` 全属性 +15%），两只精英也带 `blade`/`vengeance`/`roughskin` → **`g17` 整队被固化成一套「高攻 + 反伤 + 复仇」配置**，与其 95% → 57% 的下移方向自洽。
3. **`g18-10` Boss 带 `magicmirror`**（受指向性辅助 30% 免疫并反弹负面）——本档玩家携带 `spotlight`（support，指向性嘲讽）与 `vitality`，`magicmirror` 可能**免疫/反弹部分辅助**，是 `g18` 下移的一个次要嫌疑，**未单独验证**。
4. **`g19-10` 仍是 `[lastword, doom]`**（`doom` 无视防御与减伤，直接吃掉本档 `goldshield`/`block`/敌方 `bulwark` 等一切减伤）→ **墙的机制未变**，与 `doc/HANDOFF.md` §6.3 / §10 记录一致。
5. **`g20-10` 由「温和的 `[blizzard, heal]`」变为「4 天赋 `plain/magicshield/regen/roughskin`」** → 与其 8% → 0% 的归零自洽（`plain` 免疫属性减益会削弱玩家的陨石/巨石降属性路线，若该档有配）。

> ⚠️ 以上为**编成层面的线索**，与 §3.2 的版本 bisect 相互印证；但「天赋固化 → 难度上升」这一因果链**未做单变量验证**（需在 v2.2.16 上单独回退固化才能证明），如实记录为**未完全验证的机制线索**。

## 4. 异常 / 存疑点

1. **档位显著下移，且单层可定位（`v2.2.16`）——这是本轮最重要、且与任务预期相反的结论**：
