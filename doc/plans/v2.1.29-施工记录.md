## 1. 现状勘察（改之前的事实）

- `page/group-levels.js:12-19` `GROUP_STAGE_NAMES`：1~18 共 18 个名字。
- `page/group-levels.js:250-253` 生成循环 **写死** `for (var lg = 1; lg <= 18; lg++)`。
  → 这是关卡总数的**唯一**生成点，扩关必须改它；改名字表而漏改循环 = 名字白加。
- `page/group-progress.js:42-49` `allStageIds()` 由 `GROUP_LEVELS` 派生 → 扩关自动跟随，**不用改**。
- `page/group-levels.js:34-39` `groupTailMul(lg)`：
  - g13~g15 用 `GROUP_TAIL_POW = 1.45`
  - g16+ 用 `GROUP_TAIL_POW_EXT = 1.24`（v2.1.19 加，因为 1.45 叠到 g18 需 6~7 倍属性 = 永远碰不到）
- `scripts/test-group-levels.js:34` **写死** `groupKeys.length === 18`，扩关必挂。
- 2026-09-16 实测基线（账号 攻2883/防1145/血24800/魂攻532/魂防99）：
  g1~g13 100%、g14 43%、g15~g18 0%；
  50% 胜率所需**属性倍率** = g14 1.17× / g15 1.86× / g16 2.38× / g17 3.23× / g18 4.09×。

## 2. 做法

### A/B. 名字表 + 派生大关数

```js
var GROUP_STAGE_NAMES = { ..., 19:'试炼·太虚', 20:'试炼·混元', 21:'试炼·无极' };

/* v2.1.29：大关数由名字表派生（此前写死 18，加名字不加关卡的坑） */
var GROUP_MAX = Number(Object.keys(GROUP_STAGE_NAMES).length);
```

生成循环 `lg <= 18` → `lg <= GROUP_MAX`。
**以后扩关只需往名字表里加一行。**

### 难度斜率：g19~g21 沿用 `GROUP_TAIL_POW_EXT = 1.24`

理由：现有阶梯 g16 2.38× → g17 3.23× → g18 4.09×，档间比约 1.27~1.36。
继续 1.24 得到 g19≈5.1× / g20≈6.3× / g21≈7.8×，**与既有阶梯连续**，不引入新拐点。
不新加第三档斜率 —— 那是新的 [PLACEHOLDER]，除非 D 项实测发现明显失控。

### C. 测试派生

`test-group-levels.js:34` 改为从 `GROUP_STAGE_NAMES` 取长度（保持「仍能断言到一个具体数」，
但不再写死字面量 18）。

### D. 测量

跑 `scripts/balance-sim.js`，对 g19/g20/g21 扫属性倍率，记录 50% 胜率门槛，
与基线 g18 4.09× 对照。**若超过 10× 判定为「永远碰不到」，回来改斜率。**

### D. 平衡实测（基准账号 攻2883/防1145/血24800/魂攻532/魂防99，宠物 SR+SSR，trials=16）

| 大关 | Boss atk/def/hp | 50% 胜率倍率 | 胜率曲线要点 |
|---|---|---|---|
| g16 | 2437/1243/16453 | 2× | — |
| g17 | 3191/1627/21541 | 3.5× | — |
| g18 | 4166/2124/28123 | 3.2× | 3×:25% → 3.5×:75% → 4×:94% |
| **g19** | 5425/2767/36624 | **4.4×** | 4×:13% → 4.5×:56% → 5×:75% |
| **g20** | 7049/3595/47586 | **3.5×** | 3×:0% → 3.5×:50% → 4×:88% ← **比 g19 简单（倒挂）** |
| **g21** | 9140/4661/61700 | **8.3×** | 7×:0% → 7.5×:6% → 8×:25% → 8.5×:63% ← **悬崖** |

**归因（不是斜率问题）** —— 各关词条/技能是按 `(大关,小关,槽位)` 播种的确定性随机：
- g19 Boss 抽到 `doom_call + grow_atk`，技能 `lastword + doom`（特级负面/同归于尽）→ 最凶组合
- g20 Boss 抽到温和的 `grow_def + grow_atk`，技能 `blizzard + heal`
- g21 Boss 抽到 `aoe_guard + skill_guard`（**双减伤**），精英一只有 `extra_act`（额外行动）

即：敌人数值只差 1.24~1.30×，但词条回答把实际难度差放大到 2.4×。
**未在本版改动**（属设计决策，待 dundun 定夺）→ 已列入待处理事项。
