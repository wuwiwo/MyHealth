# MyHealth v1.4 Release Notes / 变更日志

**Date:** 2026-06-16

## 自 v1.3 以来的变更

### 新增功能

| 功能 | 说明 |
|------|------|
| 🎯 关卡预览弹窗 | 点击关卡卡片预览敌人属性、Boss词缀、胜率估算，确认后挑战 |
| 📊 属性日志增量显示 | 绿色 +N / 红色 -N 标识每次属性变化，原因明确到"容量+420kg→攻+21" |
| 📝 日志原因细节 | 记录 strVol/carEff 差分 + 周奖励 + 惩罚详情 |

### Bug 修复

| 修复 | 说明 |
|------|------|
| 🩹 有氧计划按钮不显示 | 空计划时也渲染按钮 |

| 🩹 热力图双标题 | 去除静态 HTML 标题 |
| 🩹 防御公式 | `10+⌊有效时长/15⌋`（强度加权） |
| 🩹 战斗 HP 条分母 | 修复为 player.maxHP |
| 🩹 NaN 体重拒绝 | 验证 isNaN/w≤0/w>500 |
| 🩹 图表除零崩溃 | range = Math.max(1, ...) |
| 🩹 setTheme 空值 | 添加 null guard |
| 🩹 训练定时器泄漏 | 关闭遮罩时清除 setInterval |
| 🩹 热力图年份越界 | 限制 2020~明年 |
| 🩹 图表文字描边 | 去除 strokeText |
| 🩹 本周统计单位 | 添加"次"/"kg"，显示真实最爱动作+训练天数 |
| 🩹 属性日志死代码 | 惩罚信息改用 permPenAtk+permPenDef |
