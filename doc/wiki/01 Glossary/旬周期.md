# 术语：旬周期

**定义**：把自然月切成上旬（1–10）/ 中旬（11–20）/ 下旬（21–月末）三段，按活跃天数与容量给永久攻防奖励、按上旬活跃天数不足给永久惩罚。

**现行规则**：`periodDays >= 6` → `atk + 30`；`periodVol >= round(2500 × periodDays / 10)` → `atk + 60`；可叠加；`defBonus = round(atkBonus / 5)`。永久惩罚 `missDays = max(0, 6 - lastPeriodDays)`，`atkPen = round(missDays × 3)`、`defPen = round(missDays × 1.5)`。

**代码**：`page/stats.js:76-95`（`getCurrentPeriod`）、`:123-133`（`calculatePeriodBonus`）、`:142-149`（`calculatePeriodPenalty`）、`page/game-render.js:262-264`（累加 `g.permPen`）。

**旧称**：`6天→+30攻防` 漏掉容量档与防由攻派生，且旧文档把永久惩罚误记为「挑战失败累积」，均已废弃。
