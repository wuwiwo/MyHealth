# 术语：宠物

**定义**：蛋 → 成长 → 成熟三阶段的养成单位，成熟宠物以独立单位参与 [[敌群|敌群]] 战斗；属性由图鉴基础值 + 炼化 + 凝聚 / 共鸣构成基础部分，再乘稀有度与宝珠组成的百分比池。

**现行规模**：图鉴 **14 只**（R3 / SR4 / SSR4 / UR3）；`PET_BATTLE_MAX = 4`；存档 `dh-pets-v1`。

**代码**：`page/pet-codex.js`、`page/pets.js`、`page/pet-materials.js`、`page/pet-store.js`、`page/pet-ui.js`。

**旧称**：`最多上场 2 只` 是 v2.2.0 之前的口径，已废弃；「12+1 / 13 只」图鉴数与「天赋可装配」同样过时（天赋固有、`getPetTalents()` 忽略存档 `talentIds`）。
