# 术语：玩家技能

**定义**：由技能点升级、装配到 3 个槽位、经 `player-skill-hooks.js` 接入群战引擎的玩家侧技能；与敌群技能、宠物技能是三套不同注册表。

**现行规模**：**10 个**技能（`crit / vitality / meteor / block / momentum / icebeam / goldshield / spotlight / boulder / qifeng`），`SKILL_SLOT_TOTAL = 3` 且 3 槽全开；技能点基数 `SKILL_POINTS_PER_STAGE = 4`。

**代码**：`page/skills.js`、`page/skill-store.js`（`dh-skills-v1`）、`page/skill-ui.js`、`page/player-skill-hooks.js`、`page/game-render.js:1807`。

**旧称**：`9 选 1` 对应旧「9 个技能 / 单槽 / 按月解锁」口径，已废弃；`unlockSkillSlots()` 全项目无调用点，槽位由 `getSkillState()` 读路径抬到 3。
