# 隐藏挑战

> 事实源：`page/challenge.js`、`page/orbs.js`、`page/skill-store.js`、`page/pet-store.js`。
> 核对版本：`2.14.16` / `5e4d15c`。相关：[[01 训练与属性统计]]、[[05 宠物系统]]、[[06 宝珠系统]]、[[07 玩家技能与媒体资源]]。

## 1. 召唤池与成功率

- 门槛：每 **100kg 今日容量 = 1 次**召唤机会，`todayPool = floor(今日容量 / 100)`（`challenge.js:129,147`）。
- `summonRate(used)`（`:90-97`），`used` = 今日已失败次数：`u >= 5` → **100%**；`u === 4` → **80%**；否则 `min(100, 10 + u × 15)` → **10 / 25 / 40 / 55 / 80 / 100**。
- 双池：今日池 `floor(今日容量/100)`（成功写 `summonedDate`，每日 1 次守卫）；补召池 `floor(昨日容量/100)`，昨日漏召顺延 1 天，成功写 `madeUpDate`（`madeUpUsed` 单独计数，`:151-162`）。补召结算不占今日名额。
- 存档键 `challenge`（`dh-challenge-v1`），见 [[08 数据持久化与云同步]]。

## 2. 战斗小游戏

- 时长 `CH_DUR_MIN = 6`、`CH_DUR_MAX = 8` 秒（`:55,431`），注释明确 **v2.4.10 前为 8–12 秒**；热血 buff 的 `timeBonus` 会把时长 ×1.4（`:435-440`）。
- 基础伤害 = `攻 × 0.5 + 魂攻 × 1.5 + 防 + 魂防`；基础暴击 **20% × 1.5**（`:401`）。
- **热血 buff**：本周去重天数 ≥ 5 且未使用时 3 选 1（`:417-420,375-380`）：
  - `critRate` 0.20 → 0.75 / 1.5 → 1.85；
  - `critDmg` 0.35 / 2.7；
  - `timeBonus` 时长 × 1.4。
- 挑战周计数 `challengeWeek` 是运行时字段，`wkKey = 'W' + ceil(日 / 7)`（`:614-617`），分档 2–3 / 4 / ≥5 次（`:619`）。

## 3. 属性奖励

- `CH_REWARD_DIV = { atk: 1575, def: 2362.5, hp: 472.5, hpStep: 3 }`（`:49`）。
- `bonusAtk = floor(dmg / 1575)`、`bonusDef = floor(dmg / 2362.5)`、`bonusHp = floor(dmg / 472.5) × 3`（`:560-562`），累加进 `seasonBonus`；`resetChallengeSeason()` 每月清零（`:931-938`）。
- 该月奖经 `challengeBonus.atk / def` 进入 `calculateStats()`，见 [[01 训练与属性统计]]。

## 4. 掉落

- 每次胜利（`:603-661`）：营养液 5–10 / 饲料 3–7 / 炼化石 2–4 / 高炼石 0–2 / 灵能 1–4 / 宝珠碎片 4–8；`DROP_MULT = { orbShard: 3, refineNormal: 2, refineHigh: 2, spirit: 2 }`（`:15`）。
- **技能点**：基础 **20 / 次**（直加 `ss.points`），再按周次数档 2–3 / 4 / ≥5 次给 6–10 / 8–12 / 50–75（`:610,622-635,672`）。⚠️ 与敌群发点是**两条独立代码路径**（敌群走 `awardSkillPoints`），见 [[07 玩家技能与媒体资源]]。
- **宝珠**：每次胜利 1 颗，`ORB_DROP_RATES = { R: .60, SR: .25, SSR: .12, UR: .03 }`（`orbs.js:59`）；结算面板展示宝珠名 / 品质 / `orbPct` 与 32px 图标（`:715-720`）。
- **宠物蛋**：周内 ≥5 次时随机给一只未拥有的蛋（`:639-650`）。
- 结算面板 `endChallenge()`（`:552`）把结果写入 `#challengeModal` 的 `.modal-sheet`（`:727-729`），含「本月属性奖励」与「材料掉落」区块（`:696-722`）。

## 5. 与旧文档的差异

`doc/HANDOFF.md` §6.2 写「8–12s 倒计时」「周内 4 天连续解锁热血 buff」，均为旧口径；现行是 **6–8 秒**、**≥5 天**。`CONTEXT.md` 旧版未覆盖隐藏挑战。完整对照见 [[12 术语表与过时文档对照]]。
