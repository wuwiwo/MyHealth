# 训练与属性统计

> 事实源：`page/stats.js`、`page/app.js`、`page/game-render.js`、`page/level-system.js`、`page/level-titles.js`、`page/game-records.js`、`page/tab-strength.js`、`page/tab-profile.js`、`page/utils.js`、`page/data/exercises-dataset.js`、`page/ex-dataset.js`。
> 核对版本：`2.14.16` / `5e4d15c`。相关：[[08 数据持久化与云同步]]、[[03 隐藏挑战]]、[[02 关卡试炼与单敌战斗]]。

## 1. 训练记录与容量

- **力量条目**存 `strength.entries`：`{ id, date, exercise, weight, actualReps, targetReps?, createdAt }`；**有氧条目**存 `cardio.entries`：`{ id, date, type, duration, distance?, intensity?, createdAt }`。
- **容量 `sumVolume()`**（`stats.js:13-22`）：
  `Σ w × n × (ratio / 100)`
  - `w = e.eqWeight != null ? e.eqWeight : (e.weight || 0)` —— **自重等效重量优先**；
  - `n = e.actualReps || e.duration || 0`；
  - `ratio = exerciseMap[e.exercise].ratio ?? 100`，乘在 `w × n` 上。
- **PR 不乘 ratio**：`checkPR()`（`app.js:10-21`）用 `vol = w × n`，字段 `maxWeight / maxReps / maxVolume` + 各自日期。
- **有效时长 `sumEffectiveDuration()`**（`stats.js:39-44`）：`Σ (duration || 0) × intensity`；`intensity = e.intensity || typeMap[e.type].intensity ?? 1`，系数即 1 / 2 / 3。`sumDuration()` 返回原始分钟数。
- 默认 **20 个力量动作**、**6 类有氧**（`app.js:268,271-278`）；有氧默认强度：跑步 2 / 跳绳 3 / 骑行 2 / 游泳 3 / 快走 1 / HIIT 3。
- 动作库字段：`id, name, type, ratio, intensity, emoji, hasDist, description, eqWeight, unit, dsId`；`eqWeight` = 自重动作等效重量（`null` = 哑铃动作），`unit` = `rep` | `sec`。
- 自定义重量边界（`tab-strength.js:20`）：`WT_MIN = 0.5`、`WT_MAX = 200`、`WT_STEP = 0.5`。
- **动作百科**：`page/data/exercises-dataset.js` 的 `EX_DATASET.items` 共 **1324 条**，13 个键、20 条 aliases；查询层 `EXD`（`ex-dataset.js:185-201`）提供 `ready/attribution/count/get/row/norm/matchCandidates/search/cats/eqs/mediaUrls` 等；`dsId` 由 `app.js:151-164` 用 `matchCandidates` 回填，改名/合并时继承。

## 2. 玩家属性 `calculateStats()`

- **统计窗口是「本月」**：`getGameStats()`（`game-render.js:226-234`）取 `monthStart` = 当月 1 号。`stats.js:155` 的注释写「30-day」与实现**不符**，不要照注释理解。
- 公式（`stats.js:164-177`）：

```text
baseAtk = 10 + floor(strVol / 20)
baseDef = 10 + floor(carEff / 15)
B       = pAtk + pDef
atk     = max(1, baseAtk + pAtk - permPenAtk + floor(rb.atk))
def     = max(1, baseDef + pDef - permPenDef + floor(rb.def))
hp      = 100 + floor(strVol / 10) + floor(carDur / 3) + B * 3 + floor(rb.hp) + cHp
soulAtk = floor(rb.soulAtk)      soulDef = floor(rb.soulDef)
```

- 只有 `atk / def` 有 `max(1, …)` 下限；`hp` 与魂攻防**无上限、无 clamp**。
- 入参（`game-render.js:286`）：`pAtk = permBonusAtk + challengeBonus.atk`、`pDef = permBonusDef + challengeBonus.def`（累积旬奖 + 隐藏挑战月奖），`permPen` 来自 `g.permPen`。
- `countActiveDays()`（`stats.js:52-57`）注释宣称返回 `{ days, bonus }`，**实际只返回 `days.size`**，没有 bonus 字段；`getMonthDays()` 仅用于展示。等级周结算只改经验，不进此式（`level-system.js:411-416`）。

## 3. 旬周期与永久惩罚

- `getCurrentPeriod()`（`stats.js:76-95`）：1–10 日上旬 / 11–20 日中旬 / 21 日至月末下旬；容量阈值 `volThreshold = round(2500 × periodDays / 10)`（10 天 → 2500；下旬 8 / 10 / 11 天 → 2000 / 2500 / 2750）。
- 活跃天数 = 力量 + 有氧 `date` 去重后的 Set 大小（`stats.js:59-64`）。
- `calculatePeriodBonus()`（`stats.js:123-133`）三旬同一公式：
  - `periodDays >= 6` → `atk + 30`；
  - `periodVol >= volThreshold` → `atk + 60`；
  - 两条可叠加 → `atk +30 / +60 / +90`，`defBonus = round(atkBonus / 5)` = 6 / 12 / 18，**防由攻派生**。
- **永久惩罚不是「挑战失败累积」**，而是**上旬活跃天数不足**：`calculatePeriodPenalty()`（`stats.js:142-149`）
  `missDays = max(0, 6 - lastPeriodDays)`、`atkPen = round(missDays × 3)`、`defPen = round(missDays × 1.5)`；
  `getGameStats()` 按 `penKey` 每旬累加一次到 `g.permPen`（`game-render.js:262-264`）；`PERIOD_RULE_START = '2026-07-01'`（`game-render.js:212`）之前不生效。

## 4. 炼魂系统

- 解锁条件：`g.cleared.includes('9-6')`（`game-render.js:270-273`）。
- 点数来源：本月容量 `floor(strVol / 100) × 10` 的**增量补发**（`stats.js:223-224`、`game-render.js:275-283`）+ 关卡战斗炼化点（`game-battle.js:636-637`）。
- 品质 **9 级** `F / E / D / C / B / A / R / SR / SSR`（`stats.js:180-191`），强化 5 属性 `atk / def / hp / soulAtk / soulDef`；`maxLevel` 依次 `10 / 15 / 20 / 30 / 40 / 50 / 60 / 80 / 100`；成功率 `.95 / .8 / .75 / .6 / .5 / .4 / .3 / .2 / .1`。
- **每月重置** `checkMonthlyReset()`（`app.js:320-340`）：`refine` 归零（`points / totalEarned / unlocked / upgrades`），并清 `game.cleared / current / attempts`、调用 `resetChallengeSeason()`。

## 5. 角色等级、称号与记录

- `level-system.js`：10kg 有效容量或 5min 有效时长 = 1 经验（`:32-33`）；初始 lv1，升级需 `目标等级 × 10`（`:35-37`）；26 档 lv10 ~ lv2100（`:77-104`）；周 4 天达标 +500、未达标每天 −1000（`:44-46,411-416`）；季度清零（`:450-466`）。
- 称号 `LEVEL_TITLES` **27 条**（`level-titles.js:31-59`，lv1 基线 + 26 档），`levelTitle()` 取 ≤lv 的最大键。
- `prs` 存 PR；`attrLog` 由 `trackStats()` 写、上限 **100 条**（`game-records.js:19-50`）；`records` 由 `trackLevel()` 写 `maxCleared` / 月最佳（`:8-17`）。

## 6. 主题与热力图

- 主题**三态** `system / dark / light`，默认 `system` 跟随系统（`getTheme / effTheme / setTheme / toggleTheme`，`utils.js:162-172`）。
- 热力图 `renderHeatmap()`（`tab-profile.js:222-245`），容器 `#profileHeatmap`，vol / count 双模式、5 级，由 `switchSub('profile','training')` 触发（`app.js:244`）。
