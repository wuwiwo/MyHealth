# 关卡试炼与单敌战斗

> 事实源：`page/levels.js`、`page/battle.js`、`page/game-battle.js`、`page/game-render.js`。
> 核对版本：`2.14.16` / `5e4d15c`。
> ⚠️ 这是**单敌**系统，与 [[04 敌群多对多战斗]] 是两套独立关卡，不要混用数字。养成输入见 [[01 训练与属性统计]]，炼魂解锁见本页 §6。

## 1. 关卡表 `LEVELS`

- `page/levels.js:5-298` 是**静态字面量对象**，运行时不生成，挂 `window / globalThis`（`:301-302`）；注释说明数值由构建期脚本按 **1.113×** 外推写死（`:246-281`）。
- **35 章 201 关**：chap1–3 各 3 关，chap4–35 各 6 关；ID 格式 `'章-关'`（`1-1` ~ `35-6`），键 `chap1` ~ `chap35`。
- `boss: true` 共 **32** 个，均为 `x-6`，首个 `4-6`（`:27`）；`dualAffix: true` 共 **20** 个，首个 `16-6`（`:123`），16 章起 Boss 抽 2 个词条（`battle.js:47,104-106`）。
- 首个非零 `soulAtk` 在 **`10-1` = 50**（`:70`）；缺字段按 0（`battle.js:117`）。
- 关卡形态固定编排（`:246-281`）：`x-1` 均衡 / `x-2` 高攻低防 / `x-3` 高防高血 / `x-4` 最高攻 / `x-5` 次高攻 / `x-6` Boss（atk 中上、def/hp 最高）。
- 章数**没有硬编码**：徽标 `Object.keys(LEVELS).length`、解锁链 `allPrevCleared()`、`findLevel()` 全部遍历 `LEVELS`，扩章只需加一个 chap 块。

## 2. 单敌回合顺序 `battleTick()`（`battle.js:173-262`）

```text
turn++ → onTurnStart hook → affix.onTurn（怒气 / 铁壁）
→ 玩家物理 rollDamage(atk, def, 4) + 虚弱减免 → applySingleBattleDamage
→ 荆棘反伤（基于护盾吸收前的 pDmg）→ 敌死判定
→ 玩家魂攻 → 敌死判定
→ 敌物理 /3 → 敌魂攻 → 汲取回血 → 玩家死判定 → onTurnEnd
```

- `applySingleBattleDamage()`（`:135-159`）：`raw = floor(max(0, dmg))` → `shieldAbsorbed = min(_shield, raw)` → `hpDamage = min(hp, raw - shieldAbsorbed)`，**先扣盾后扣 HP**；护盾同时吸收物理与魂伤（`:134,213`）。
- `rollDamage()`（`:128-130`）：`max(1, atk - floor(def / 2) + floor(rng * variance) + 1)`；玩家物理 variance = 4，敌方物理 / 魂攻 variance = 3。
- 魂结算：玩家 `rollDamage(soulAtk, enemy.soulDef, 4)`、敌 `rollDamage(enemy.soulAtk, player.soulDef, 3)`；无对应防御时魂攻**全额伤害**。

## 3. Boss 词缀 `BOSS_AFFIXES`（`battle.js:24-45`，共 5 条）

| 词缀 | 效果 |
|---|---|
| 虚弱诅咒 | 玩家 `def < 50` 时，玩家 atk 变为 `floor(atk × (0.8 + rng × 0.1))` |
| 荆棘之躯 | 反伤 `max(1, floor(dmg × 0.5) - floor(atkDef / 2))` |
| 怒气勃发 | `turn >= 2` 且回合数能被 2 或 3 整除且 `rng < 0.6` → atk 累加 1~5，可叠加 |
| 生命汲取 | 累加 `floor(dmg × 0.25)` 到 `_heal` |
| 铁壁护盾 | `turn >= 3` 且能被 3 整除且 `rng < 0.5` → `_shield += floor(baseAtk × 0.3) × 2`，且 atk += `floor(baseAtk × 0.1)` |

- `BOSS_LIFESTEAL_RATE = 0.25`（`:22`）。作者 2026-10-06 裁决：单敌 Boss「生命汲取」按敌方物理伤害恢复 **25%**，实现去掉 `_heal × 0.5` 的二次减半，日志报实际回复。
- 已确认的代码裁决：**单敌魂伤会过护盾**（`battle.js:213-222`）；**荆棘反伤基数是护盾吸收前的伤害**（`:30-31,193-203`）。

## 4. 失败次数、战利品与自动推进

- **每日每关 3 次**挑战机会，key = `today() + '_' + id`（`game-battle.js:177-180,619-622`）。
- 战利品是**炼化点**（不是技能点）：`rollLoot()`（`:133-138`）`base = 1~2`，普通关 ×2、Boss 关 ×10 → 2 / 4 或 10 / 20，写入 `ref.points`（`:636-638`）。
  ⚠️ 代码在**每次胜利**都发放，`cleared` 只做去重记录（`:628`），**没有「首通」条件判断**。
- **auto 推进**：胜负层 800ms（`:705`）→ 战果层；`won && _battleAuto && nextId` 时展示 ≥ **2000ms** 后 `startBattle(getGame().current)`（`:688,693-694`），合计约 **2800ms**；要求 overlay 仍 open、`current` 非空。

## 5. 与炼魂 / 月重置的接口

- 炼魂解锁固定挂在 `9-6`（`game-render.js:270-273`），与章数无关。
- 月重置 `checkMonthlyReset()` 会清空 `game.cleared / current / attempts`（`app.js:320-340`），因此单敌进度是按月重来的；详见 [[01 训练与属性统计]]。
