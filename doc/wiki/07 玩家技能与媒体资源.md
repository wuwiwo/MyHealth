# 玩家技能与媒体资源

> 事实源：`page/skills.js`、`page/skill-store.js`、`page/skill-ui.js`、`page/player-skill-hooks.js`、`page/game-render.js`、`page/challenge.js`、`page/config.js`、`page/ex-dataset.js`、`page/media/`。
> 核对版本：`2.14.16` / `5e4d15c`。相关：[[04 敌群多对多战斗]]、[[03 隐藏挑战]]、[[09 UI 设计体系与无障碍]]。

## 1. 技能注册表

- 实际 **10 个**（`skills.js:40-128`）：`crit` 暴击 / `vitality` 气力恢复 / `meteor` 陨石轰炸 / `block` 格挡 / `momentum` 气势如虹 / `icebeam` 冰魄光束 / `goldshield` 金身护盾 / `spotlight` 瞩目 / `boulder` 巨石重压 / `qifeng` 启风。文件头注释「9」已过时。
- 升级消耗 `(当前 lv + 1) × 系数`（`:23`），10 个技能系数依次 `10 / 15 / 5 / 15 / 10 / 6 / 15 / 10 / 5 / 15`。
- 装备槽 `SKILL_SLOT_TOTAL = 3`、`slotsUnlocked = 3`、`loadout = []`（`:155,158`）→ **3 槽已全开**；同类型限 1（`:188`）。`unlockSkillSlots()` **全项目无调用点 / 未接线**（`skill-store.js:23`），靠 `getSkillState()` 读路径把槽位抬到 3（`:26`）。
- ⚠️ 旧文档写 `9 个技能 / 9 选 1 / 槽位按月通关解锁` 均已过时。

## 2. 技能点经济

- `SKILL_POINTS_PER_STAGE = 4`（`skill-store.js:36`）是唯一基数来源。
- 敌群胜利：`earnSkillPoints = base × (1 + min(2.5, (win - 1) × 0.5))`（`skills.js:133-141`）→ 4 / 6 / 8 / 10 / 12 / 14 封顶；`game-render.js:1807` 走 `recordSkillWin + awardSkillPoints`，见 [[04 敌群多对多战斗]]。
- 隐藏挑战**直发 20 / 次** + 周次数档 2–3 / 4 / ≥5 次给 6–10 / 8–12 / 50–75（`challenge.js:610,622-635,672`），是**另一条独立代码路径**，见 [[03 隐藏挑战]]。
- 存档键 `dh-skills-v1`（`points / levels / loadout / slotsUnlocked`）；月重置 `monthlyResetSkillState()` 清零技能点 + 技能等级减半（`skill-store.js:91-101`）。

## 3. 战斗挂钩

- `player-skill-hooks.js:11-375`：`attachPlayerSkills` / `battleStart`（金身）/ `CritHook` / `BlockHook` / `TurnStart`（气势、气力、瞩目、启风）/ `TurnEnd`（瞩目）/ `AttackSkill`（陨石、冰魄、巨石）/ `shieldPreSnapshot` · `ReflectAfter` / `qifengExtraAttack` / `attachPetSharedSkills`。
- **关键接线**：`startGroupTrial()` 里必须 `attachPlayerSkills(player, getSkillState())`，玩家技能才生效。
- **「瞩目」**：`spotlight` maxLv 10、`chance = lv × 0.04`（满级 40%）、`tauntDur 1`（`skills.js:105`）；触发置 `_taunting / _spotHits`、挂 `vigil`（受伤 −15%、2 回合）、锁 2 回合、pity ×1.2（`player-skill-hooks.js:167-187`）；回合末全体回复 `(def + soulDef) × 受击次数`（`:278-295`）。`:167` 注释写「n × 3%」与 effect 的 4% 不符。

## 4. 媒体资源

- `page/media/` 下 SVG 数量：**pets 14 / monsters 18 / skills 48 / orbs 5**；另有 `images/ 19`、`videos/ 19` 非 SVG。
- 统一规格：`48×48`、`viewBox="0 0 48 48"`、`shape-rendering="crispEdges"`、16×16 像素网格（1 格 3px），与 [[06 宝珠系统]] 的 5 枚宝珠图标同风格。`pets/` 的 14 个文件名与 14 只图鉴一一对应，见 [[05 宠物系统]]。
- `MEDIA_BASE = ''`（`config.js:4`），空值 = 本地 `page/media/` 相对路径；`mediaUrls(rel)`（`ex-dataset.js:179`）图床优先、回退 `'media/' + rel`。**图标走硬编码 `media/`，不经 `MEDIA_BASE`**。
- 加载顺序约束（`page/index.html:290-295`）：`skill-icon.js` 必须早于 `game-render.js`；`monster-archetype.js` 在 `levels.js` 之后。

## 5. 动作百科

- `page/data/exercises-dataset.js` 的 `EX_DATASET.items` 共 **1324 条**（字段 13 个：`id,name,zh,cat,eq,target,mg,sec,img,gif,mid,ins,steps`；20 条 aliases；署名 © Gym visual；updated 2026-08-27）。
- `EXD` 接口（`ex-dataset.js:185-201`）：`ready / attribution / count / get / row / norm / matchCandidates / search / cats / eqs / getCatLabel / getEqLabel / toZh / tagHtml / mediaUrls`；`get()` 按 `dsId` 查，缺失返回 `null`（`:81`）；`search()` 支持全文 + `cat` / `eq` 筛选（`:138`）。
- `dsId` 存动作对象 `ex.dsId`：`app.js:151-164` 用 `matchCandidates` 回填 `cands[0].item.id`，改名 / 合并时继承（`:60-71`）；`tab-settings.js:63`、`tab-strength.js:786` 用 `EXD.get(ex.dsId)`，见 [[01 训练与属性统计]]。
