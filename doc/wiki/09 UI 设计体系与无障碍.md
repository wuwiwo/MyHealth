# UI 设计体系与无障碍

> 事实源：`doc/design-tokens-v2.1.md`（现行规范）、`page/index.css`、`scripts/test-a11y-tokens.js`、`page/game-views.js`、`page/pet-ui.js`、`page/challenge.js`。
> 核对版本：`2.14.16` / `5e4d15c`。相关：[[10 测试与版本纪律]]、[[06 宝珠系统]]、[[07 玩家技能与媒体资源]]。

## 1. 扁平设计硬规则（`design-tokens-v2.1.md` §14，`:317-396`）

- **0 圆角**：`--rad-*: 0`，仅 `--rad-circle: 50%` 例外。
- **无阴影**（`--sh-*: none`）、**无渐变**、**无半透明**（`opacity < 0.5` 禁止）、**无模糊**。
- 结构描边 `--bw: 2px`；过渡时长 `0 ~ 75ms`；hover 反色；focus 2px 描边；配色为黑白 + 单一强调色。
- §15（`:400-511`）科技蓝 `--brand*`；`:483-487` 规定原生 `<details>/<summary>` 的 summary 触控尺寸 322×44。

## 2. 令牌速查

- `--touch-min: 44px`（`:147,337`）；密集筛选条例外 36px（`:176`）；字阶 10 档（`:105-118`）。
- `page/index.css` `:root`（`:9-94`）主要值：`--brand #60A5FA`、`--brand-fill #2563EB`、`--on-brand #fff`、`--bg #0b1120`、`--surface #111827`、`--bd #475569`、`--bw 2px`、`--rad-* 0`、`--sh-* none`、`--dur-* 0/75ms`、`--mw 500px`、`--tabbar-h 48px`、`--touch-min 44px`；浅色主题覆盖在 `:95-110`。
- 主题三态 `system / dark / light`，见 [[01 训练与属性统计]]。

## 3. 无障碍约定

- `scripts/test-a11y-tokens.js` **40 项**断言（`design-tokens-v2.1.md:5,290`；`doc/HANDOFF.md:398`），8 组（`:56-243`），静态 25 处 + 运行期 40；输出格式 `ALL PASS (40/40)`。其中含「无静默 catch（均带日志 / 用户反馈 /『忽略』说明）」。
- `aria-pressed` 是选中态的**唯一来源**，由 CSS 负责上色；例如 `.train-pick-chip[aria-pressed="true"]:not(:hover)`（`page/index.css`），避免视觉态与无障碍态漂移。
- `<details>/<summary>` 用原生可聚焦行为（Enter / Space、`:focus-visible` 2px 描边），不自建 `aria-expanded`；**主数值不折叠**。折叠用于宝珠库存、宠物次要分组、培养页材料 / 获取记录。
- `role="tablist" / "tab" / "dialog" / "status"`、`aria-labelledby` 带文件前缀（`design-tokens-v2.1.md` §7.2，`:210`）。

## 4. v2.14.16 新增样式类

| 类 | 用途 |
|---|---|
| `.orb-ico` | 宝珠图标，`image-rendering: pixelated / crisp-edges` |

| `.train-lineup` / `.train-lineup-hd` / `.train-lineup-count` / `.train-lineup-hint` / `.train-lineup-chips` / `.train-lineup-empty` / `.train-pick-chip` / `.train-start-battle` / `.train-more-pet` | 培养页常驻出战阵容卡 |

- 宝珠槽位图标尺寸为 **32px**（16×16 像素网格的整数倍），早期 `24px` 已修正，见 [[06 宝珠系统]]。
- 培养页阵容卡与折叠的事件接线见 [[04 敌群多对多战斗]] §3；出战阵容复用 `_petBattlePicks` / `ensurePetBattlePicksLoaded()` / `savePetBattlePicks()`，与 `pet-ui.js` 同源。

## 5. 改动 UI 时的护栏

1. 只用既有令牌，不新增字号 / 颜色；
2. 触控目标 ≥ `var(--touch-min)`；
3. 折叠用原生 `<details>/<summary>`；
4. 选中态用 `aria-pressed` 同源；
5. 改完必须跑 `node scripts/test-a11y-tokens.js` 与全量回归，见 [[10 测试与版本纪律]]。
