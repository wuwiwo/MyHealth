# 宝珠系统

> 事实源：`page/orbs.js`、`page/pet-ui.js`、`page/pet-store.js`、`page/challenge.js`、`page/media/orbs/*.svg`、`page/index.css`。
> 核对版本：`2.14.16` / `5e4d15c`（v2.15 口径）。相关：[[05 宠物系统]]、[[03 隐藏挑战]]、[[04 敌群多对多战斗]]、[[08 数据持久化与云同步]]。

## 1. 数据模型与数值唯一源

- 宝珠对象 `{ id, type, rarity, level }`；字段 `rarity` 是历史命名，实际语义为品质 `R / SR / SSR / UR`。
- `ORB_TYPES` **5 种**：`hp / atk / soulAtk / def / soulDef`（`orbs.js:37`）。
- `ORB_QUALITY_SPEC`（`:48`）是**唯一数值源**：

| 品质 | base | grow | maxLv | 满级后升品质 |
|---|---|---|---|---|
| R | 10 | 1 | 10 | → SR |
| SR | 20 | 2 | 25 | → SSR |
| SSR | 70 | 2 | 40 | → UR |
| UR | 150 | 3 | 50 | — |

- `orbPct(orb) = min(ORB_PCT_CAP, base + (level - 1) × grow)`，`ORB_PCT_CAP = 300`（`:81`）；UR Lv50 = **+297%**。
- `ORB_DROP_RATES = { R: .60, SR: .25, SSR: .12, UR: .03 }`（`:59`）；隐藏挑战每胜 1 颗（`challenge.js:652-661`），见 [[03 隐藏挑战]]。
- 加成不是直接加属性值：`petOrbPct()` 汇总 → `createPetUnit()` 挂 `unit._orbPct` → 与稀有度倍率、共鸣**加算**进百分比池（`pet-store.js:430-453`），见 [[05 宠物系统]]。

## 2. 升级 / 装配 / 月重置 / 迁移

- 升级消耗 `(lv + 1) × 2` 碎片（`:56,108`）；**满级自动升品质**、level 回 1（`:115-131`），加成连续（R 满 19% → SR Lv1 20%）。
- 装配 **5 槽**，每类型 1 颗（`:218-223`；`pet-ui.js:110`）。
- 月重置：等级回 1、**品质保留**，碎片清空（`:233-243`），由 `monthlyResetPets()` 调用，见 [[05 宠物系统]]。
- `migrateOrbs()`（`:253-285`，挂在 `getPetStore()` 读路径且幂等）：旧 **N 档每颗 → 20 碎片**；R / SR / SSR 品质映射 + 等级保号，超新上限截断；**不发放补偿**。

## 3. v2.15 分解：等价碎片

- 旧常量 `ORB_DECOMPOSE = { R:8, SR:10, SSR:20, UR:40 }` **已删除**（`orbs.js:27` 仅剩注释，全库无定义）。
- 作者裁决「**等同加成 %**」：`orbDecomposeShards(orb) = orbPct(orb)`（`:138`）。
  - `R·Lv1 = 10`（用户指定基准）、`R·Lv10 = 19`、`SR·Lv1 = 20`、`SR·Lv25 = 68`、`SSR·Lv1 = 70`、`SSR·Lv40 = 148`、`UR·Lv1 = 150`、`UR·Lv50 = 297`。
- `decomposeOrb()` 改用该函数，`pet-ui.js` 分解按钮与 toast 显示实际返还数；`MATERIAL_SOURCES.orbShard` 改为「隐藏挑战胜利掉落 / 分解宝珠返还（等价碎片）」。

## 4. v2.15 每日合成（恢复）

- 常量（`orbs.js:61-63`）：`ORB_SYNTH_COST = 20`、`ORB_SYNTH_DAILY_LIMIT = 5`、`ORB_SYNTH_RARITY = 'R'`。
- **20 碎片 → 随机 1 颗 R·Lv1 宝珠，100% 成功，每天最多 5 次**。
- `synthOrb(data, todayKey)`（`:201`）：
  - 先取 `orbSynthStatus(data, todayKey)`；不可合成时直接返回，**失败不扣碎片、不计数**（`:204`）。
  - 扣除 20 碎片 → `createOrb(randomOrbType(), 'R')` → 写入 `data.orbs` → `data.orbSynth = { dayKey, count }`。
  - 创建失败（类型表未加载）同样不扣。
- **跨日读时重置**：`orbSynthState()`（`:178-184`）发现 `dayKey !== todayKey` 即归零，**无定时任务**；不追溯补偿。
- `todayKey` 由 UI 注入 `dateKey(new Date())`（`pet-ui.js:512,514`），`orbs.js` 保持纯逻辑，不依赖 `Date` / DOM / store。
- 计数存 `data.orbSynth`，放在 `pets` 存档对象内部，随云同步 `keys` 自动派生，不新增 store key（`pet-store.js` 的 `defaultValue()` 与旧档补齐），见 [[08 数据持久化与云同步]]。

## 5. UI 与图标

- `orbIconHtml(type, size)`（`pet-ui.js:62`）：唯一图标入口，URL = `'media/orbs/' + type + '.svg'`（`:57`），**不走 `MEDIA_BASE`**；调用统一传 **32**（`:98,127,129`）。32px 是 16×16 网格的整数倍；早期 `24px` 已修正。
- `page/media/orbs/` 5 枚：`hp.svg / atk.svg / def.svg / soulAtk.svg / soulDef.svg`；全部 `48×48`、`viewBox="0 0 48 48"`、`shape-rendering="crispEdges"`、16×16 网格（1 格 3px），带 `<title>`，风格与 `media/pets/*.svg`、`media/skills/*.svg` 一致。
- 宝珠库存 `orbBagHtml()`：常显合成按钮 `data-orb-synth`，用 `orbSynthStatus()` 渲染「今日合成 count/limit」与禁用原因（独立 `.orb-synth-hint`），库存列表放进原生 `<details class="orb-stock">` 默认折叠。
- `challenge.js:715-720` 结算面板用 `orbIconHtml(type, 32)` + 品质 + `orbPct%`；因 `challenge.js` 早于 `pet-ui.js` 加载，用 `typeof orbIconHtml === 'function'` 守卫，缺模块时退回 `🔮`。
- 相关 CSS（`.orb-ico`、`.orb-bag`、`.orb-stock`、`.orb-synth-hint`）见 [[09 UI 设计体系与无障碍]]。

## 6. 升级提示 bug 修复（v2.14.16）

`upgradeOrb()` 返回 `{ ok, level, rarity, promoted, pct }`，**没有 `stat` 字段**；旧 UI 读 `u8.stat` 导致 toast 显示 `+undefined`。现改为 `u8.pct`，并在 `u8.promoted` 时追加「升品质 `<rarity>`」。`scripts/test-orb-wiring.js` 有源码守卫禁止 `u8.stat` 字面量再次出现。
