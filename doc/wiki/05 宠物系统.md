# 宠物系统

> 事实源：`page/pet-codex.js`、`page/pets.js`、`page/pet-materials.js`、`page/pet-store.js`、`page/pet-ui.js`、`page/group-levels.js`。
> 核对版本：`2.14.16` / `5e4d15c`。相关：[[04 敌群多对多战斗]]、[[06 宝珠系统]]、[[08 数据持久化与云同步]]。
> 平衡现状与未实装项的评审材料：`doc/design-pet-balance-v1.md`、`doc/design-pet-roster-v1.md`（历史评审，不作事实源）。

## 1. 图鉴与稀有度

- `PET_CODEX` 共 **14 只**（`pet-codex.js:10-29`）：**R 3 / SR 4 / SSR 4 / UR 3**。文件头注释「13 只」已过时。
- **初始属性倾向未实装**：`base` 固定，同稀有度属性逐字段相同（`:12-28`），代码中无 tendency 字段；`doc/design-pet-roster-v1.md` 是提案。
- **天赋固有、不可跨宠物装配**（`:31-39`；`pet-materials.js:200-202` 已删解锁接口）：R / SR 无天赋，例外 `pongpong = pig_snore`（`:14,36`）；SSR 单天赋、UR 双天赋（`:21-28`）。`getPetTalents()` 恒取图鉴值、**忽略存档 `talentIds`**（`:41-46`）。

## 2. 生命周期

- 三阶段：`createPet stage = 'egg'`（`pets.js:61`）→ 成长：`hatchProgress >= 100`（`hatchCheck:300`），营养液每次 +0.5~2%（`feedNutrition:196`）→ 成熟：`growth >= 100`（`feedPet:219`），健康 > 50 时每日自然 +1~7%（`PET_CONFIG:18`），喂饲料 +2~5（`:216`）。
- `hatchDays = 14` 仅作参考，蛋期按天**不推进**（`:10,235`）。
- 喂食：营养液 +0.5~2% / 饲料饥饿 +10~15%（`:11-12`）；成长 1~7% / 天（`:18`）；成熟每天耗饥饿 20~35%（`:19`）。
- **受伤**：`matureInjuryChance = 0.5`（`:24`）；营养液 +10~15% / 饲料 +4~5% 恢复，`injuryHeal` 满 100 解除（`:25,36-46`）；敌群战败由 `applyDefeatInjuries()`（`pet-store.js:182`）触发。
- **阵亡**：health 归零置 `isDead / deadAt`（`pets.js:244-248`），`settlePet()` 对 `isDead` 直接 return（`:279`）；全库**无复活写回**（`isDead = false` 仅出现在 `:220` 转成熟）→ **复活未实装**。
- **蛋来源**：初始赠 1 颗（`pet-store.js:78-88`）；隐藏挑战周内 ≥5 次随机给未拥有的蛋（`challenge.js:639-650`），见 [[03 隐藏挑战]]。
- `challengeWeek` 不是 schema 字段，运行时 `d.challengeWeek[wkKey]++`、`wkKey = 'W' + ceil(日/7)`（`challenge.js:614-617`）。

## 3. 属性模型

- `createPetUnit()`（`pet-codex.js:50-96`）= 图鉴 `base` + `refineStats`（`:62`）+ `_talentMods`（`:86`），挂 `_orbPct`（`:94`）、`_skillLevels` / `_refineLevel`（`:79-83`）。
- 稀有度放大 `PET_GROUP_SCALE = { R:1200, SR:1400, SSR:1500, UR:1600 }`（`group-levels.js:65`）。
- **团队凝聚** `TEAM_COHESION_PCT = 3`（`pet-store.js:347`）；**共鸣** `PET_RESONANCE_SCALE = { UR:10, SSR:8, SR:7, R:6 }`（`:350`）；`PET_BONUS_ATTRS` 不含 `spd`（`:351`）。
- 最终属性（`pet-store.js:430-453`）：`floor((base + 凝聚) × (稀有度% + Σ宝珠% + Σ共鸣%) / 100)`；**速度不参与百分比池**（`:332,444`）。
- 顺序守卫：建单位 → 基础值加成（凝聚 / 共鸣）→ 稀有度放大，见 [[04 敌群多对多战斗]]。

## 4. 炼化与技能

- 炼化上限 `refineMaxLevel`：**R 50 / SR 60 / SSR 80 / UR 100**（`pet-materials.js:34`）。
- `refineSuccessRate()`（`:41-52`）：基础 0.7；高级石 `<50` = 1.0 / `50~80` = 0.8 / `80~100` = 0.7；普通石 `lv >= 50` = 0。
- `refineStatGain()` 只覆盖 5 项、**不含 spd**（`:55-61`）；**突破未实装**（全项目仅 `levels.js:168` 有同名关卡名）。
- 炼化石兑换：普通 → 高级 **10:1**（`exchangeRefineStones`）；宠物技能升级 `upgradePetSkill()` 消耗 ✨ 灵能、上限 Lv10。
- 宠物技能 / 天赋的实战接线与 14 个天赋清单见 `doc/HANDOFF.md` §6.5（历史快照）与 [[04 敌群多对多战斗]]。

## 5. 存档 `dh-pets-v1`

- schema 字段（`pet-store.js:12-33`）：`version / pets / materials{nutrition,feed,spirit,refineNormal,refineHigh,orbShard} / orbs / battlePicks / lastSettleDate / monthlyKey / levelLedger{monthKey,dayKey,dailyGranted,challengeKeys,log} / orbSynth{dayKey,count}`。
- 运行时动态字段：`materialLog`（`grantMaterial:95`，最近 20 条 `{type,n,date,ts}`）、`challengeWeek`（`challenge.js:614`）。
- `MATERIAL_SOURCES`（`:114-121`）：营养液 10–20% / 饲料 20–30% / 灵能 5–10% / 普通炼化石 隐藏挑战 / 高级炼化石 Boss 关 / 宝珠碎片 隐藏挑战 + 分解返还。
- **月重置** `monthlyResetPets()`（`:195-209`）：`monthlyKey` 幂等；逐宠炼化清零 + 技能减半 + `monthlyResetOrbs()`（宝珠等级回 1、碎片清空）+ 6 种材料清零。技能点另在 `dh-skills-v1` 的 `monthlyResetSkillState()` 清零 + 减半（`skill-store.js:91-101`）。
- `battlePicks` 与 `PET_BATTLE_MAX = 4`（`:301-303`）是敌群参战阵容的唯一来源，见 [[04 敌群多对多战斗]]。

## 6. 已知平衡现状（评审材料，非代码规则）

`doc/design-pet-balance-v1.md`（2026-10-11 实测）记录：同稀有度属性逐字段相同；炼化 0 时 14 只宠物在 g14/15 胜率全 0%；满炼化 R 血 4800 = 裸 UR 血 4800，全跨度 20×；8/14 只技能在 t=0 形同没有；速度不参与炼化、突破未实装。这些是**评审结论**，不是现行数值规则。
