## 1. 项目是什么

个人健身健康管理单页应用：把力量训练与有氧记录折算成 RPG 角色属性，再用这些属性去打**两套互相独立**的战斗系统。纯前端（原生 JS + HTML + CSS，无框架、无构建），数据存 localStorage，经 Vercel Serverless `/api/data` 做 Blob 云同步。

- 运行形态：`page/index.html` 底部按依赖顺序加载 54 个 `<script src>` + 1 段 `init()`；`page/vercel.json` 的 `outputDirectory: "."`（部署根为 `page/`）。
- 版本唯一源：`page/utils.js` 的 `APP_VERSION`；缓存戳以 `page/index.html` 实际值为准。
- 现状速查：[[10 测试与版本纪律]]、[[11 部署与运维]]。

## 5. 维护纪律

- **只改文档属于设计阶段**：用 `docs:` 前缀提交，**不** bump `APP_VERSION`、不生成 changelog、不动架构演化表（`AGENTS.md`）。
- 改代码即进入施工阶段：bump 版本 + README 版本表 + changelog + 架构演化表 + cache-busting，并跑全量 `scripts/test-*.js`。
- 新增大类时：新建一页 → 在本页「大类导航」「阅读顺序」与下方「全部页面」各补一条 `[[...]]` → 运行 `check`。
- 本套文档全部使用**裸名 wikilink**（不带目录路径），因此无论把 `doc/wiki/` 还是把整个仓库作为 Obsidian vault 打开，链接都能解析。
- 数值写进文档必须带代码位置；旧值统一放进 [[12 术语表与过时文档对照]]，不要在各页正文重复。
