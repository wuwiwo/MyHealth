## 3. 问题清单

### P0
无。没有阻塞主流程或造成数据风险的缺陷。

### P1（正确性 / 明显错版 / 遮挡可操作区）

**P1-A 本旬目标第三卡换行错位** · `page/game-views.js:312,320`
`wkStatus` 是拼好的字符串 `'💪 0/6天'`，塞进 `flex:1` 的三等分卡（360 下每卡约 100px），`fs-lg` 下自然折行；「状态」二字作为独立 label 被推到「天」的下方，视觉读成 `0/6 / 天 / 状态`。
修法：值拆成「数字 + 单位」两个 span（单位 `--fs-xs` 且 `nowrap`），或把三卡改成 2 列 + 1 列跨行；label「状态」语义本身也需改（应为「本旬达标」或「达标天数」）。

**P1-B 调试 FAB 遮挡可点目标** · `page/debug.js:402-406`、`page/index.css:1097`
`.debug-fab` 是 `position:fixed; right:12px; bottom:…` 的 44px 圆钮（`opacity:.55`、`title="debug"`），在 360 宽下永久压住滚动内容的右列。实测：动作库第三卡的 🗑️ 完全被圆覆盖，挑战页第 12 张关卡卡右半被覆盖——**这是唯一一处"点不准"的真问题**，且触发者是一次误点删除/误入关卡。
修法：① 非调试构建隐藏该 FAB（它本来只是 debug 入口）；② 若必须保留，移到 `bottom: 96px` 以上 + `z-index` 降级 + 内容区加 `padding-right` 安全区（`index.css:143` 现有注释只加了底部安全内边距，未处理右侧）。

**P1-C 图鉴激活页签计数不可读** · `page/index.css:1341-1342`、`page/codex.js:616`
`.codex-tab-n` 常态 `--text3` 尚可，但 `.codex-tab.active` 把它改成 `--orange`，而激活页签背景是实心蓝 → 实测 **1.3:1**（"14" 几乎消失）。
修法：激活态计数用 `rgba(255,255,255,.85)` 或直接 `--bg`；或激活态改「白底蓝字 + 蓝下边框」的轻量选中样式（同时缓解下面 P3 的"双行实心蓝"）。

1. **双行实心蓝**：顶栏 active tab + 子 tab active 同时整块填充，且区块标题的蓝色细下划线与同色 → 蓝色同时承担"选中/装饰/主操作"三种语义（`train-*`、`game-*` 全部页面都有）。
