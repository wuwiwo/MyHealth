## 1. 设计规则（必须遵守的既有约束）

1. **稀有度决定天赋数**：R/SR 无天赋（若 `design-pet-balance-v1.md` P7 被采纳则改为「各 1 个」），
   SSR 单天赋、UR 双天赋。天赋**固定值**、**不接成长区间**（`2.2-修改提案.md` §3.11B）。
2. **技能数值走区间**：`t = 炼化等级 ÷ 稀有度上限`，`值 = 下限 + (上限−下限)×t`（`skill.js:134-167`）。
   新技能必须给 `range`，且**下限不得为 0**（否则重蹈 t=0 空转，见 D4）。
3. **天赋必须 `petOnly: true`**，否则 `enemy.js` 的 `pickRandomTalents` 会抽给敌人。
4. **状态 duration = 实际回合数 + 1**（在本回合内施加时，同回合末 `ageStatuses` 先扣 1；见 `p_sleep` 注释）。
5. **优先复用既有通道**（成本 0/1），避免新增引擎能力（成本 2）。已验证可复用的通道：

| 通道 | 位置 | 可做什么 |
|---|---|---|
| `_shield` + `absorbShield()` | `battle-group.js:45-53` | 给单位加护盾（伤害前吸收、破盾清 `_shieldImmune`） |
| `_shieldImmune` | `player-skill-hooks.js:41` | ⚠️ **副作用**：`_shield > 0` 时**免疫普通~高级负面** —— 给宠物开盾会顺带送状态免疫，必须显式裁决（见 §2.4） |
| `dmgTakenReduce` | `battle-group.js` 两条伤害通道 | 减伤（可连乘） |
| `reflectFlat` | `battle-group.js:744`（消费者）；`talent.js:249`（现有生产者） | 反伤（`onDamage` 返回 mutations） |
| `poison` 状态 | `status-defs.js:9-24` | DOT：每回合末 `maxHP×4%`，Boss 减半，`maxStacks:1`/`refresh` |
| `slow` / `haste` | `status-defs.js:217-268` | 速度：`slow` 是**固定 −3**；`haste` 走实例 `modsPct`（百分比） |
| `wideguard` | `status-defs.js:326-347` | 减伤状态，幅度由实例 `data.reduce` 携带（兜底 0.20） |
| `guardup` | `status-defs.js:306-315` | 坚壁：防/魂防 +10%/层，最多 5 层，`stack` |
| `lifesteal` buff / `onAfterDamage` | `pet-codex.js` `p_warmight`；`talent.js` 嗜血 | 吸血（可挂在持有者身上或天赋通道） |
| `cleanseNegatives(unit, maxGrade)` | 供 `p_sleep` 使用 | 清除自身普通~高级负面 |
| `condBonus` | `skill.js`（`p_thundercharge` 用） | 按**目标状态**加伤 |
| `bounce` / `multiHit` / `enemy2` / `enemy12` / `ally2` / `wounded` | `skill.js` | 弹射 / 多段 / 多目标 / 只挑未满血友方 |

6. **不新增引擎能力的硬边界**：全项目无 `onKill` 派发点、无「额外行动」派发点、无「致死免疫」通道 → 相关设计一律标成本 2，不纳入本提案（见 §2.6 末尾）。

## 2. 候选宠物（6 只）

> 每只给出：定位 / 稀有度 / 属性倾向（§2.9 符号，每符号 ±15%）/ 技能 / 天赋 / 实现成本 / 平衡自检。
> 「成本」：**0 = 纯数据**；**1 = 复用既有通道或新增一个状态定义**；**2 = 需新增引擎能力**。

### 2.1 石砾龟（R · 守护 / 反伤）— 批 1

| 项 | 内容 |
|---|---|
| 定位 | R 级「能站住」的坦克：把「被打」变成收益，让 R 级在低炼化期也有存在感 |
| 属性倾向（提案） | 血 `+++` / 攻 `---` / 防 `+++` / 魂攻 `--` / 魂防 `++` / 速 `---` |
| 技能 | **缩壳** `p_shell`：`type:'support'`、`target:'self'`、`cooldown:3`、`range:{ reduce:[15,35], reflect:[20,40] }` |
| 效果 | 自身获得状态 `shell` **2 回合**（= 实际 1 回合 +1）：受到伤害 −`reduce`%，并把**本次受到伤害的** `reflect`% 反伤给攻击者（走 `reflectFlat` 消费者） |
| 天赋 | 无（R 级规则；若采纳 P7 则加「壳内再生」：自身有 `shell` 时每回合末回复 maxHP×5%） |
| 成本 | **1**（新增状态定义 `shell`，复用 `dmgTakenReduce` + `reflectFlat` 两条既有通道） |
| t=0 效果 | 减伤 15%、反伤 20%（**非空转**，符合 P2 纪律） |
| 平衡自检 | 反伤按「受到伤害的 20%~40%」缩放（而非固定值），在 g16-18 高攻敌人面前才有意义；与坚强岩（坚壁：防+10%/层×5）**定位不重叠** —— 坚强岩是自身变硬，石砾龟是**惩罚攻击者** |
| 风险 | 反伤走 `reflectFlat` 会**穿透护盾**（消费者直接扣 `actor.hp`，见 `battle-group.js:744`）→ 属既有口径，需在裁决时确认是否接受 |

### 2.2 铁壁犀（SSR · 群体护盾）— 批 1

| 项 | 内容 |
|---|---|
| 定位 | 首个**群体护盾**宠：把「预判伤害」变成可操作资源，替代「治疗事后补血」 |
| 属性倾向（提案） | 血 `+++` / 攻 `--` / 防 `++++` / 魂攻 `--` / 魂防 `+++` / 速 `---` |
| 技能 | **岩甲** `p_bulwark`：`type:'support'`、`target:'all'`（我方全体）、`cooldown:4`、`range:{ shield:[200,400] }` |
| 效果 | 我方全体获得护盾 = **施法者防御 × `shield`%**，持续 2 回合；护盾由 `absorbShield()` 在伤害结算前吸收 |
| 天赋 | **磐石** `bedrock`（`petOnly`）：自身处于护盾中时受到伤害 −15%（`onDamage` → `dmgTakenReduce 0.15`） |
| 成本 | **1**（写入 `_shield` 无需新通道；天赋复用 `onDamage`） |
| 数值自检 | SSR 满炼化防御 945 → 护盾 3780（t=1）；裸装防御 225 → 450（t=0）。对照同稀有度光之精灵单点治疗 150%~240%×魂攻(1185) ≈ 1778~2844/回合，**护盾总量更高但只挡不治**（不可叠加、2 回合过期） |
| ⚠️ 必须裁决 | **`_shield > 0` ⇒ `_shieldImmune = true`（免疫普通~高级负面）** 是玩家金身护盾的既有口径（`player-skill-hooks.js:41`）。给宠物开盾若沿用该字段，等于**全队白送状态免疫**（冰冻/睡眠/中毒/降攻防全免）→ 严重超模。两个选项：**(a)** 宠物护盾只写 `_shield`、不写 `_shieldImmune`（需拆开该赋值，成本 1，属改动玩家技能链路，须回归）；**(b)** 接受白送免疫并把护盾量砍到 `[80,160]%`。**建议 (a)**，并把「护盾与状态免疫解耦」列为独立小任务 |

### 2.3 苔藓菇（SR · DOT 专精）— 批 2

| 项 | 内容 |
|---|---|
| 定位 | 首个 DOT 宠：对高防/Boss 这类「打不动」的目标，用百分比伤害绕开防御 |
| 属性倾向（提案） | 血 `++` / 攻 `--` / 防 `+` / 魂攻 `++` / 魂防 `+` / 速 `---` |
| 技能 | **孢子云** `p_spore`：`type:'support'`、`target:'enemy2'`、`cooldown:4`、`range:{ pct:[3,6], duration:[2,4] }` |
| 效果 | 对最多 2 名敌人施加 `poison`，每回合末损失 `maxHP × pct`%（Boss 减半沿用既有口径），持续 `duration` 回合 |
| 天赋 | 无（SR 级规则） |
| 成本 | **1**（需给 `poison` 加可选实例幅度 `st.data.pct`，**无 data 时回落到 0.04**，保证敌人中毒行为一字不变 —— 与 `wideguard` 的「定义值仅兜底」写法一致） |
| t=0 效果 | 毒伤 3%、持续 2 回合（非空转） |
| 平衡自检 | 单次施放的期望总伤 = 2 目标 × `duration` 回合 × `maxHP×pct`。以 g16 Boss（maxHP 量级数万）为例，t=1 时 ≈ 2×4×6% = **48% maxHP**（Boss 减半 → 24%）—— 与雷霆犬单发 440% 魂攻相当但**分布更慢、可被净化**。`maxStacks:1` + `refresh` 意味着**不能叠层**，只能刷新，这是刻意的上限 |
| 风险 | 改 `poison` 定义会同时影响敌人中毒（若实例无 `data` 则不变，需断言锁死）；「毒伤吃不吃减伤/防御」按既有口径（不吃，纯 maxHP 百分比）→ 需在裁决中确认 |

### 2.4 风铃雀（SR · 速度轴）— 批 2

| 项 | 内容 |
|---|---|
| 定位 | 首个**速度轴**宠：改变行动顺序，与「速度不可炼化」（D6）形成互补 —— 想抢先手只能靠它 |
| 属性倾向（提案） | 血 `=` / 攻 `--` / 防 `--` / 魂攻 `+` / 魂防 `=` / 速 `++++` |
| 技能 | **逆风铃** `p_tailwind`：`type:'support'`、`target:'all'`、`cooldown:5`、`range:{ allySpd:[10,25], foeSpd:[10,25] }` |
| 效果 | 我方全体速度 +`allySpd`%（2 回合）；敌方全体速度 −`foeSpd`%（2 回合）。双方都走**实例 `modsPct.spd`**（与 `haste` 同一写法） |
| 天赋 | 无（SR 级规则） |
| 成本 | **1**（新增状态 `slowed`（镜像 `haste`，带实例 `modsPct.spd`）；`haste` 直接复用） |
| t=0 效果 | 双方 ±10%（非空转） |
| 平衡自检 | 速度是**顺序轴**而非数值轴：+25% 在 spd 6→7.5 量级上通常只改变 1 个位次，**不直接放大伤害**，属安全设计。对照「瞩目」（`_taunting` 使速度 ×2）—— 风铃雀是**全场**小幅度，瞩目是单点翻倍，两者不冲突 |
| 风险 | 速度改变会连带改变 AI 选靶与先手结算 → **固定种子战斗输出必然变化**（与 P4 选 A 同性质）。若 P4 采纳「B 回改文档（速度不可炼化）」，本宠物反而成为**唯一的速度来源**，价值上升 |

### 2.5 幽火烛（SSR · 吸血输出）— 批 3

| 项 | 内容 |
|---|---|
| 定位 | 以吸血为核心的**自续航输出**：适合长线战斗（Boss/高血量关），与「无念熊（爆发）/梦幻（弹射）」区分 |
| 属性倾向（提案） | 血 `+` / 攻 `+` / 防 `--` / 魂攻 `+++` / 魂防 `--` / 速 `++` |
| 技能 | **噬魂焰** `p_soulflame`：`type:'attack'`、`target:'random1'`、`dmgType:'soul'`、`cooldown:4`、`range:{ power:[200,300], ls:[20,40] }` |
| 效果 | 对随机 1 敌造成 `魂攻 × power`% 魂伤；同时给自身挂 `warmight` 同源的 `lifesteal` buff（幅度 `ls`%，2 回合）→ 复用 `p_warmight` 的吸血载体 |
| 天赋 | **魂噬** `soul_devour`（`petOnly`）：自身造成魂攻伤害时回复其 15%（走 `onAfterDamage`；参考实现是**敌人**天赋「嗜血」`talent.js:520-534`，同样是「`ctx.dealt × 比例` 直接回 `unit.hp`、上限 maxHP」；本天赋按宠物天赋纪律取**固定值**，不接区间） |
| 成本 | **0**（技能复用 `lifesteal` buff 通道；天赋复用 `onAfterDamage`，且是**新增注册**、不改动敌人天赋「嗜血」） |
| t=0 效果 | 伤害 200%、吸血 20%（非空转） |
| 平衡自检 | 峰值单发 300% 魂攻 + 双重吸血（技能 40% + 天赋 15% = 55%）→ 单次 300% 魂攻(1600)=4800 伤可回 **2640** 血。**上限控制点**：SSR 魂攻 1185(t=1)，且吸血只对**实际造成的伤害**生效（护盾吸收不计，沿用 v2.9.0 口径）→ 对高防/高盾目标自然衰减 |
| 风险 | 吸血与「圣光麒麟 战意灌注」的吸血**叠加**（两者都挂在持有者身上）→ 需断言「同源不重复触发」，或明确允许叠加 |

### 2.6 时之砂（UR · Boss 特化 / 控制）— 批 3

| 项 | 内容 |
|---|---|
| 定位 | 首个 **Boss 特化**宠：对 Boss/精英有额外收益，填补「打 Boss 只能堆数值」的空白 |
| 属性倾向（提案） | 血 `+` / 攻 `+` / 防 `++` / 魂攻 `+` / 魂防 `++` / 速 `+` |
| 技能 | **停滞领域** `p_stasis`：`type:'support'`、`target:'all'`（敌方全体）、`cooldown:5`、`range:{ spdDown:[15,35], bossTurn:[1,2] }` |
| 效果 | 敌方全体速度 −`spdDown`%（2 回合）；**若目标带 `boss` tag**（`unit.tags` 已含该标记，`poison` 亦按它减半），则持续时间额外 +`bossTurn` 回合 |
| 天赋① | **时砂之瞳** `sand_eye`（`petOnly`）：我方全体**免疫特级负面**（`grade 3`：末日 / 遗言诅咒）。走 `onAllyStatus` + `ctx.grade`（与 `winter_core` 同一派发点，仅把判据从 `freeze` 换成 `grade >= 3`） |
| 天赋② | **砂之净化** `sand_purge`（`petOnly`）：每 3 回合开始清除我方全体普通~高级负面一次（`onTurnStart` 遍历 `ctx.allyUnits` + `cleanseNegatives(u, 2)`，与「灵感涌动」同一派发点） |
| 成本 | **1**（技能复用 `slowed`；两个天赋都复用既有 hook 与 `cleanseNegatives`） |
| t=0 效果 | 减速 15%、Boss 额外 1 回合（非空转） |
| 平衡自检 | 该宠**零直接伤害**，价值全在「拖慢敌人 + 免疫特级负面 + 定期净化」→ 与 UR 的「输出」定位互补（现有 UR 两只都是输出型）。对非 Boss 关卡，天赋①基本无效（末日/遗言主要由 Boss 施加）→ 属**场景特化**，符合设计意图 |
| 风险 | 「免疫特级负面」目前只有 `immovable`（仅自身、血量 >95%）触及；扩到**全队免疫**是明显加强，需评估对 g20+ Boss 战（末日/遗言是主要威胁）的难度影响 |
| **已剔除的设计** | 原设想「致死免疫（首次致死保留 1 点生命）」与「使友方获得额外行动」**均已剔除** —— 引擎无对应通道（无 `onKill`、无额外行动派发点），属成本 2，按 §1.6 硬边界不纳入本提案 |
