## 4. 问题清单

### P1（发布前必修）

**P1-1 同一组数据在一个面板里渲染两次**
- 位置：`page/pet-ui.js:391–411`（参战阵容）与 `:309–340`（首发队卡）
- 证据：量测 `pickNames=[闪闪星,梦幻]`、`squad1Selected=[✓闪闪星,✓梦幻]` —— 完全同一组；两处都显示 `2/4`，都能改选中。
- 影响：用户要自己推断「上面这块和下面一队是什么关系」；两处可分别点击 → 状态分裂风险（一处是 `savePetBattlePicks` 镜像，一处是 `togglePetSquadPet`）。
- 与既定裁决冲突：你上一轮定的是「**用多队入口代替参战阵容模块**」，现在实际是「多队入口 + 参战模块并存」。
- 修法：删掉参战阵容块，把开战按钮提到编队区顶部；或把它降级为**只读一行**摘要（`首发：闪闪星 梦幻 2/4 · 管理 ›`），点击即进编队区。

**P1-2 选中态靠内联样式，但被全局 `!important` 静默覆盖**
- 位置：`page/pet-ui.js:404`（内联 `border-color/color/background`）+ `page/index.css:1419`
- 机制：`[style*="border-color"]` 命中所有带内联 border-color 的 `.speed-btn` → `color:var(--text)!important` 覆盖内联 `color:var(--on-brand)`。
- 实测后果：选中芯片按钮自身 `color=rgb(28,25,23)`，于是内部 `currentColor` 描边的「在 X队」标签变成近黑框（`.pet-squad-chip-tag` 用 `border:...solid currentColor`）。
- 影响：维护者以为内联生效，实际不生效；以后再加内联样式会继续被这条吃掉。
- 修法：选中态 100% 交给类（`.pet-pick-chip.is-sel`），删掉内联样式；把 1419 那条守卫收窄到只匹配历史调用点，或改为 `.pet-pick-chip:not(.is-sel)` 的反向限定。

### P2（下一轮修）

**P2-3 关卡标签 9/10 重复 = 噪声**
- 位置：`page/game-views.js` `showGroupStages` + `page/group-levels.js:stageModeLabel`
- 证据：g3 十张卡，「双场景」出现 9 次，唯一有信息量的是第 10 关「双 BOSS」。
- 影响：标签把卡片压成 4 层（图标 / 关名 / 标签 / 锁+未解锁），扫读变慢；真正的例外被稀释。
- 修法：**反向标注** —— 只给例外打标（`双 BOSS`），常规形态写在列表头（`本大关 10 关 · 均为双场景 · 第 10 关双 BOSS`）。

**P2-4 培养页编队行没有任何「可点」提示**
- 位置：`page/game-views.js:125–134`；量测 `hasAffordance=false`
- 影响：整行是 `button`，但视觉上像静态摘要（无 `›`、无 hover 变化、无下划线），用户不会想到点它能进编辑。
- 修法：右上或行尾加 `›`，行内加 `点开编辑` 的次级提示，并给 `.train-squad-row:hover/.active` 加底色反馈。

**P2-5 同一概念三种叫法**
- `首发 / 作战`（编队区徽标，`pet-ui.js:312`）、`首发 / 第 2 队`（培养页，`game-views.js:129`）、`一队 / 二队`（默认队名）。
- 修法：统一为 `首发 / 第 N 队`；`作战` 删除。

**P2-6 禁用芯片关键信息读不清**
- 位置：`page/index.css:1192` `.pet-squad-chip.is-taken{opacity:.45}`
- 证据：`#57534E` 叠 45% 不透明度到白底，有效对比 ≈ **2.1:1**，而「在 X队」正是要靠它传达的内容。
- 修法：opacity 提到 `.6`，`tag` 单独用不透明 `--text2`；或者把归属改成芯片右侧小锁图标 + 文字保留实色。

**P2-7 删除队伍无确认、无撤销，且红色语义冲突**
- 位置：`page/pet-ui.js:325–327`（`data-squad-del`）+ `index.css:1183`（红框）
- 同一红色在关卡页是「双 BOSS」（非危险），在面板是「危险销毁」。
- 修法：复用现成 confirm 弹窗；红色仅留给破坏性操作，`双 BOSS` 换成品牌色或描边加粗。

### P3（打磨）

- **P3-8** `--fs-2xs` 11px 用于标签与元信息；360 宽下中文笔画粘连，建议标签 12px、元信息保留 11px 但只放非关键信息。
- **P3-9** 同权重全宽按钮过多（开始试炼 / 编队管理 / 更多养成 / 技能 / 图鉴 / 炼魂），主 CTA 不突出；建议只保留「开始试炼」实心，其余改为列表行或次级样式。
- **P3-10** `border-radius:12px` 内联（`game-views.js:147/151/153`）被全局 0 覆盖，属死代码，顺手清。

## 5. 做得好的地方（保持）

1. **跨队占用提前否决**：不是「点了报错」，而是置灰 + 写明「已编在「一队」」+ `disabled`，错误预防做到了极少数产品才有的水平。
2. **命中区与标签覆盖**：所有交互 44px，纯图标按钮 `aria-label` 0 遗漏，全局 `:focus-visible`，这在 360 宽游戏 UI 里很少见。
3. **计数用 `tabular-nums`**、`2/4` 这类数字不跳动；空态都给了明确动作（`空队 · 点开把宠物编进来`）。
