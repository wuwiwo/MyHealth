### 1.3 新技能：启风（`qifeng`）

| 项 | 内容 |
|---|---|
| 类型 | **辅助**（与气势如虹 / 气力恢复 / 瞩目互斥，同类型最多带 1 个） |
| 满级 | 10 |
| 消耗 | **`(lv+1)×15`，升满 825**（本次由 Agent 拟定：与同档 lv10 强技能「格挡 / 金身护盾」对齐） |
| 效果① | 每回合开始，使我方随机 **2 名**角色速度 **+n%**（满级 **10%**） |
| 效果② | 若我方持有**全场速度最快**者（敌我双方合并排序），则该角色每回合可**额外进行一次普通攻击**，该次伤害为 **n×8%**（满级 **80%**），即「再打一次，但只造成 80% 伤害」 |
| 条件 | 速度最快的判定**须为敌我双方最快**；不满足则效果②不生效 |
| 速度增益 | **持续至战斗结束，或直到被驱散** —— 按「可被驱散的状态」实现（非直改 `base`） |

### 1.4 待议 / 遗留

1. **技能点经济**：见 §1.2 的 ⚠️ 项。
2. **宠物的三个新档位（暴击 / 气力恢复 / 格挡）如何获得**：
   裁决为「宠物档对宠物也生效」，但宠物**取得途径**未定 ——
   是新增宠物专属技能、并入宠物天赋，还是允许宠物装配玩家技能？
   → **并入第 2 批（宠物技能）一起裁**。
3. **`block` 现有实现需改口径**：当前是「几率 20%+lv×2%、减伤 25%+lv×5%」，
   裁决改为「几率固定、减伤随等级成长」，且新增常驻减伤 10% 与完美格挡分支。
