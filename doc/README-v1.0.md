# MyHealth v1.0

> Personal Health Manager — 个人健身健康管理应用

---

## 项目简介

MyHealth 是一个**纯前端单页应用（SPA）**，帮助用户记录和追踪个人健身数据，并通过**游戏化 RPG 挑战系统**将真实训练量转化为角色属性进行对战，提升训练动力。

### 四大功能模块

| 模块 | 图标 | 功能 |
|------|------|------|
| **力量训练** | 🏋️ | 记录力量训练动作、重量、次数；创建训练计划并跟随执行；月热力图、周统计 |
| **有氧运动** | 🏃 | 记录跑步、骑行、游泳等 6 种有氧运动，追踪时长与距离 |
| **个人资料** | 📊 | 管理身高、性别、出生年；记录体重并查看 Canvas 趋势折线图 |
| **挑战模式** | 🎮 | RPG 战斗系统：训练数据转化为攻击/防御/生命值，挑战 6 章 31 关 NPC 敌人 |

## 技术架构

```
浏览器 (localStorage) ←→ Vercel 静态站点 ←→ Vercel Blob 云存储
```

| 层级 | 技术 |
|------|------|
| **前端** | 原生 JavaScript (ES6+) + HTML5 + CSS3（CSS Variables 主题切换） |
| **后端 API** | Vercel Serverless Function（`api/data.mjs`，50 行） |
| **云存储** | Vercel Blob Storage（`@vercel/blob` SDK） |
| **部署** | Vercel（`vercel.json`，无框架，静态输出） |
| **UI 语言** | 简体中文 |

**无框架、无构建步骤、无 TypeScript、无数据库**。所有逻辑集中在单个 `index.js` 文件（1152 行）。

## 安装与部署

### 本地运行

无需安装依赖，直接用任意静态服务器打开 `page/` 目录即可：

```bash
cd page
npx serve .
# 或
python -m http.server 8080
```

### 部署到 Vercel

```bash
cd page
vercel --prod
```

依赖 `Vercel Blob Storage` 的读写 Token 环境变量：
- `BLOB_READ_WRITE_TOKEN`

## 数据同步机制

1. **离线优先**：所有数据保存在浏览器 `localStorage`
2. **自动推送**：数据变更后 800ms 防抖自动 PUT 到 Vercel Blob
3. **定时拉取**：每 2 分钟 GET 最新云端数据并合并到本地
4. **手动备份**：支持 JSON 文件导出/导入进行跨设备转移

### localStorage Key 设计

| Key | 内容 |
|-----|------|
| `dh-strength-v1` | 力量训练记录 `{entries:[]}` |
| `dh-plans-v1` | 训练计划 `{plans:[]}` |
| `dh-missed-v1` | 断签说明 `{notes:{}}` |
| `dh-cardio-v1` | 有氧运动记录 `{entries:[]}` |
| `dh-weight-v1` | 体重记录 `{records:[]}` |
| `dh-profile-v1` | 个人资料 `{height,gender,birthYear}` |
| `dh-game-v1` | 游戏进度 `{cleared:[],current:''}` |
| `dh-theme-v1` | 主题偏好 |

## 游戏化系统

### 属性计算公式

- **攻击力** = 10 + ⌊近30天力量总容量 / 20⌋ + 周奖励 - 永久惩罚
- **防御力** = 10 + ⌊近30天有氧总时长 / 6⌋ + 周奖励 - 永久惩罚
- **生命值** = 100 + ⌊近30天容量 / 10⌋ + ⌊近30天时长 / 3⌋ + 周奖励 × 3
- **周奖励**：本周训练 ≥4 天 → +20 攻/防，≥7 天 → +50 攻/防
- **永久惩罚**：上周训练 <3 天，每缺 1 天永久扣除攻击 2、防御 1

### 关卡设计（6 章 31 关）

| 章节 | 名称 | 关卡数 | Boss |
|------|------|--------|------|
| 第 1 章 | 初出茅庐 | 3 | — |
| 第 2 章 | 小试牛刀 | 3 | — |
| 第 3 章 | 锋芒初露 | 3 | — |
| 第 4 章 | 身经百战 | 6 | 暗龙 |
| 第 5 章 | 浴血奋战 | 6 | — |
| 第 6 章 | 终极试炼 | 6 | 远古龙王 |

### Boss 词缀系统

Boss 关卡随机附加特殊机制：
- **虚弱诅咒**：玩家防御 <50 时伤害减少 10-20%
- **荆棘之躯**：攻击者受到 50% 反伤
- **怒气勃发**：每 2-3 回合 Boss 攻击力递增 1-5（可叠加）

### 战斗规则
- 自动回合制战斗，支持 1×/2×/4×/8× 速度调节
- 每关每天最多挑战 3 次
- 需要先通关前置关卡才能解锁后续
- 胜利后弹出分享卡片，可截图保存

## 使用说明

### 力量训练
1. 选择日期（默认今天），点击「新增一组」
2. 输入动作名称（可从建议列表选择），选择重量 kg，设置目标/实际次数
3. 点击「记录」保存
4. 可在训练计划中创建多组计划模板，点击 ⚡ 进入跟随训练模式（含休息倒计时）

### 有氧运动
1. 选择运动类型（跑步/跳绳/骑行/游泳/快走/HIIT）
2. 设置时长（分钟）和距离（km，部分类型可选）
3. 可添加备注后记录

### 个人资料
1. 填写身高、性别、出生年
2. 输入体重并记录，体重趋势图自动更新（Canvas 绘制）

### 挑战模式
1. 查看当前属性值（攻击/防御/生命/周训练天数）
2. 点击可挑战的关卡进入战斗
3. 自动战斗结束后根据结果推进进度或消耗挑战次数
