## 总原则

1. **配色保留**：沿用现有 CSS Variables 主题色板（见 Design.md），所有调整只动布局/密度/阴影/动效，不改色彩体系。
2. **移动端优先**：真机（Android Chrome）为主验证环境；字号与点击区放大，内容更大、更易点。
3. **只读展示与编辑入口分离**：个人页、挑战页逐步转为「展示优先」，可编辑项收敛到设置页。
4. **轻动效**：过渡 ≤200ms、位移 ≤8px、透明度渐变为主；不做重动画。
5. **工程纪律**：任何文件过大/过耦合必须拆分（遵循 CONTEXT.md 模块边界）；每批改动同步更新模块边界文档。

## 一、训练页面

| # | 需求 | 润色细化 |
|---|------|----------|
| T1 | debug 按钮悬浮化 | debug 入口改为浮动按钮（FAB），支持隐藏/展开切换；默认收起为小圆钮，不遮挡内容；位置避开右侧滚动条区域 |
| T2 | 本周进度卡片间距与阴影 | 「本周 3/7 天 · 还差 1 天…」这类卡片栏与顶部标题之间增加固定间距（建议 ≥16px）；阴影由当前"脏重"改为轻盈风格——低透明度大扩散（如 `0 2px 8px rgba(0,0,0,.06)`），暗色主题用更浅的描边替代重投影 |
| T3 | 训练项目适配 GIF | 训练录入的动作选择与记录列表接入动作数据集媒体样式：已关联动作显示缩略图，详情/长按查看动画（对接 action-dataset 计划的 `dsId` 与 `exMediaUrl()`） |
| T4 | 断签"休息日"样式 | 补签面板新增可直接选择的「休息日」选项，且视觉上明显标注（区别于漏练的断签日）：独立底色/图标（如 🛌），点击即标记该日为休息而非断签 |

## 二、个人页面

| # | 需求 | 润色细化 |
|---|------|----------|
| P1 | PR 列表折叠 | 个人最佳不再全部罗列：默认显示 Top N（如 5 条）+「展开更多」折叠控制；列表项适配新图片展示（关联动作带缩略图） |
| P2 | 编辑收敛到设置页 | 基本信息（身高/性别/出生年份）在个人页**只读展示**；修改入口唯一收敛到设置页 |
| P3 | 体重小数位 | 体重数值统一格式化为 **最多 2 位小数**（`toFixed(2)` 后去尾零），杜绝长串小数 |
| P4 | 体重列表按月分组 | 体重记录列表按月分组渲染（月份标题+当月条目），默认**只展开最近一个月**，其余折叠，点击展开；避免一次性渲染全部历史 |
| P5 | 训练图表移动端适配 | 图表 canvas 尺寸自适应容器宽度；轴标签/图例字号缩小重排或抽稀（隔值显示）；触控热区可点选数据点查看数值 tooltip；确保在小屏无截断/重叠 |
| P6 | 热力图切换按钮瘦身 | 热力图「容量/次数」切换弃用图标+文字（会溢出），改为纯图标按钮 + 点击后 **toast 提示当前模式**（如「已切换：按次数」） |
| P7 | 热力图长按看数据 | 长按（long-press ~500ms）格子直接弹出当日数据气泡/toast，**不再跳转页面** |

## 五、整体

| # | 类别 | 细则 |
|---|------|------|
| O1 | 工程化 | 单文件超阈值（参考既有拆分节奏，如 >600 行）或职责耦合时**必须拆分**；拆分后同步更新 CONTEXT.md 模块边界与依赖方向 |
| O2 | 性能优化 | 列表虚拟化/分页渲染、长列表 lazy 渲染、GIF 点击播放策略（见 action-dataset 计划）、减少不必要的全量 re-render |
| O3 | UI 美化 | 内容字号与点击目标整体加大（主按钮 ≥44px 触达高度）；层次靠间距与轻阴影而非重边框；配色不动（Design.md 为准） |
| O4 | 轻动效 | 进入/切换 150–200ms 透明度+微位移；按压态 scale 反馈；数字变化滚动计数（如炼魂点数）；遵守 prefers-reduced-motion |
| O5 | AI 设计提示词资产 | 从 GitHub 检索成熟的 AI 设计相关 prompt 工程（Design.md 增强、UI 审查 checklist 等），沉淀为本仓库的设计提示词文件，服务后续 UI 迭代 |

## 七、验收要点（真机 Android Chrome）

- 卡片与顶部有可感知间距，阴影观感轻盈无脏感（明暗两主题检查）
- 所有新增点击区 ≥44px 且手感清晰；toast 提示及时消失不堆积
- 体重无一长串小数；按月折叠默认收起旧月份
- 图表在窄屏无文字重叠/截断，可点选读数
- 热力图长按出数、切换按钮不溢出
- 基本信息改名只能去设置页，个人页改后仍正确回显
- PR 默认 5 条可展开，图片在弱网降级不破版
- 训练/设置页 gif 正常显示于关联动作
- 休息日在补签面板一眼可辨
- 各页改造后跑一遍核心链路（记一组力量/有氧 → 个人页 → 挑战一场 → 设置导入导出）
