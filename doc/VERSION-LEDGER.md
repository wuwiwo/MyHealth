# 版本台账（VERSION LEDGER）

> **本仓库可能有多个 AI / 人同时开发。开工前必须先看本文件，避免两条线用同一个版本号。**
> 与本文件配套的规则写在 `AGENTS.md` 的「Version discipline → 版本台账」一节。

## 使用规则（三步：查 → 领 → 记）

> **本文件是唯一的发号处**：规则与数据都放在这里（**不写进 `AGENTS.md`** —— 那会让它越滚越长）。
> 开工前请**直接打开本文件**；开会话/开任务单时，第一个动作就是看下面的「当前领号指针」。


1. **查**：读本表，看「当前领号指针」——那就是你该用的版本号。
2. **领**：在「进行中」区登记一行（版本号 / 线或负责人 / 工作内容 / 开始日期），并把**指针 +1**。
3. **记**：提交后把该行移入「已发布」区，补上 **commit hash** 与 **changelog 文件**。

> 若两条线同时领号撞了：以**先提交者**为准，后提交者**改号后重发**，并在「历史撞号」留档。
> 历史已发布的版本号**不重写**（只留档），规则从下一次起执行。
