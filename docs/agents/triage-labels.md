# Triage Labels

## 中文标签映射

| 角色 | 中文标签 | 含义 |
|------|----------|------|
| needs-triage | `待评估` | 维护者需要过目判断 |
| needs-info | `待补充` | 等待提交者回复信息 |
| ready-for-agent | `可供代理` | 规格完整，AI 代理可直接上手 |
| ready-for-human | `需人工` | 需要开发者亲自动手 |
| wontfix | `不处理` | 不会修复或实现 |

## 使用说明

`triage` 技能会根据 issue 状态自动应用对应标签。所有标签使用中文名称。
