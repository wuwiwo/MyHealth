# Issue Tracker

## Type

GitHub Issues

## Repository

`wuwiwo/MyHealth`

## CLI

使用 `gh` 命令行工具操作：

- 创建 issue：`gh issue create --title "..." --body "..."`
- 列出 issue：`gh issue list --label "待评估"`
- 查看 issue：`gh issue view <number>`

- 仓库地址：https://github.com/wuwiwo/MyHealth
